# 学习评估页面去卡片化 — 设计方案

## 现状分析

当前 `evaluate.html` 采用 **12 列 dash-grid + dash-card** 布局，每个模块包裹在白色卡片（`background: #fff; border; border-radius; box-shadow`）中。与主页的排版驱动、无卡片风格不一致。

| 现状问题 | 说明 |
|----------|------|
| 卡片过重 | 每个模块都是独立白卡片，视觉碎片化 |
| 间距混乱 | 卡片内部 padding 不一（16/12/24px），模块间 gap 仅 10px |
| 与主页风格割裂 | 主页是流式排版 + 分割线，评估页是卡片网格 |
| 12 列网格过度设计 | 实际布局是简单的 2 列，不需要 12 列框架 |
| 加载态冗余 | 每个卡片各有一个 `empty-state` div，结构重复 |

## 设计目标

仿照主页风格，做到：

1. **去掉卡片** — 模块直接放在页面背景上，用 section-title + 分割线区分
2. **简化布局** — 用 `home-grid` 式的 2 列网格 + 全宽行，不再用 12 列
3. **统一间距** — 与主页共用同一套间距节奏
4. **排版驱动** — 靠字号、字重、间距区分层级，不靠卡片投影
5. **保留全部功能** — 4 个 Tab、ECharts 图表、测验交互、薄弱分析均保留，只改视觉层

## 各模块改造对照

### 1. KPI 统计条

| 现状 | 改造后 |
|------|--------|
| `dash-card stat-bar` 白卡片 | 取消卡片，复用主页 `.home-stats` 样式 |
| 4 个 stat-group 用 `·` 分隔 | 保持不变，去掉卡片背景、边框、阴影 |

### 2. 学习热力图

| 现状 | 改造后 |
|------|--------|
| ECharts heatmap 包在 `dash-card` 中 | 直接用 `chart-box` + section-title |
| 月份导航按钮在 card-head 内 | 移到 section-title 同行右侧 |

### 3. 遗忘预警

| 现状 | 改造后 |
|------|--------|
| 列表包在 `dash-card` 内 | 直接用 section-title + alert-item 列表 |
| 预留 `max-height:120px` 滚动 | 保持，列表项样式参考主页 `.alert-item` |

### 4. 能力雷达

| 现状 | 改造后 |
|------|--------|
| ECharts radar 包在卡片内 | 直接渲染，去掉卡片壳 |
| 评估文字在 `radar-assessment` 中 | 保留，调整为浅色背景条 |

### 5. 最近动态（时间线）

| 现状 | 改造后 |
|------|--------|
| 卡片包裹 | 直接用 `.tl-item` 列表 |
| 样式已有（dot + 竖线） | 保持现有 timeline CSS |

### 6. 学习行为趋势

| 现状 | 改造后 |
|------|--------|
| 全宽卡片 | 全宽 section，直接用 `chart-box` |
| title + subtitle 在 card-head | 改为 section-title + section-desc |

### 7. 知识点掌握度表

| 现状 | 改造后 |
|------|--------|
| 卡片包裹 | 直接用 table，表头样式保留 |
| 可排序表头 | 功能保持不变 |

### 8. 行为分布环形图 + 资源使用柱状图

| 现状 | 改造后 |
|------|--------|
| 两个图表挤在一个卡片内 | 分为两个独立区域，或保留并排但去卡片 |

### 9. Tab 栏

保持不变（`border-bottom` 下划线式，与主页风格一致）。

### 10. 测验 / 历史 / 薄弱分析 Tab

| 现状 | 改造后 |
|------|--------|
| 测验区用 `.card` 包裹选择器 | 去掉卡片，选择器直接放页面上 |
| 答题历史用 `.card` | 直接用列表 |
| 薄弱分析 `.weak-item` 带卡片样式 | 简化为左色条 + 浅色背景，去掉圆角卡片 |

## CSS 变更清单

### 删除的样式
- `.dash-grid` — 12 列网格
- `.dash-card` / `.dash-card.compact` — 卡片外壳
- `.card-head` / `.card-head .ico` — 卡片标题区
- `.card` — 通用卡片（测验/历史区）
- `.hm-arrow` — 改为复用主页 `.hm-nav-btn`
- `.stat-bar` / `.stat-group` — KPI 行改为复用 `.home-stats`

### 新增/复用样式
- `.chart-box` — ECharts 容器（已在 styles-v4.css 中，`min-height: 240px`）
- `.section-title` — 模块标题（已在 styles-v4.css 中）
- `.home-stats` — KPI 行样式（从主页复用）
- `.alert-item` — 遗忘预警项（从主页复用）
- `.tl-item` — 时间线项（从主页复用）

### 新增的评估页专属样式（少而精）
- `.eval-grid` — 简化 2 列网格（替代 12 列 dash-grid）
- `.eval-full` — 全宽 section
- `.eval-section` — section 容器，统一上下间距

## 布局节奏

```
页面标题           margin-bottom: 4px
描述文字           margin-bottom: 16px
Tab 栏             margin-bottom: 22px
KPI 行             padding: 10px 0, margin-bottom: 6px
分割线             1px solid var(--divider), margin: 10px 0 18px
模块标题           margin-bottom: 10px
图表区             高度由 ECharts 决定
模块间距           22px
2 列网格           gap: 26px（与主页一致）
```

## 不修改的部分

- JS 逻辑（数据获取、ECharts 渲染、Tab 切换、测验交互）全部保留
- 模态窗（题目详情弹窗）保持不变
- 后端 API 不涉及
- `nav.js` 侧栏集成保持不变

## 实施步骤

1. 替换 `<style>` 块：删除卡片相关 CSS，添加 eval-grid / eval-section
2. 重写 `<body>` HTML 结构：去除 `.dash-card` 包裹层
3. 调整 JS 中 DOM 选择器（如果有依赖 `.dash-card` 选择器的话）
4. 调整 ECharts 容器的宽高设置
5. 验证 4 个 Tab 均正常渲染
