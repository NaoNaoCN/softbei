# 持久化导航外壳 — 彻底消除导航闪烁

> **状态：已实施。** 方案 B（Fetch + DOM Swap）已在 `nav.js` 中实现为侧边栏 SPA 导航系统。最终采用侧边栏而非顶栏作为持久化外壳，核心原理与本文档描述一致。

## 核心思路

关键矛盾：**导航组件在所有页面都一模一样，却每次都要跟着整页重载**。

方案方向：将导航从"每页各有一份副本"改为"唯一的持久化外壳"，页面内容在其内部动态切换。

```
当前架构（每页独立）:
┌─ page A ──────────┐  点击  ┌─ page B ──────────┐
│ [nav 副本]         │ ────→  │ [nav 副本]         │
│ [content A]        │ 整页重载 │ [content B]        │
└────────────────────┘        └────────────────────┘
   nav 卸载 → 白屏 → nav 重建     ← 这就是闪烁

目标架构（持久外壳，已实施为侧边栏）:
┌─ 浏览器窗口（唯一，永不卸载）──────────────────┐
│ [sidebar — 持久 DOM，不刷新]                    │
│ ┌─ 内容区 ──────────────────────────────────┐ │
│ │ page A  →  原地替换  →  page B             │ │
│ │ (fetch + DOM swap)                        │ │
│ └───────────────────────────────────────────┘ │
└────────────────────────────────────────────────┘
```

## 方案 A：iframe 方案（最简单）

加载一个外壳页 `shell.html`，内含导航栏 + `<iframe>`。

```
shell.html:
┌──────────────────────┐
│ sidebar (持久)        │
├──────────────────────┤
│ <iframe src="...">   │  ← 导航时只改 src
│                      │
└──────────────────────┘
```

### 实现

```javascript
// shell.html 中的 nav.js
navEl.addEventListener('click', (e) => {
    const link = e.target.closest('a');
    if (!link) return;
    e.preventDefault();
    document.getElementById('content-frame').src = link.getAttribute('href');
});
```

### 优点
- 极其简单，20 行代码
- 导航外壳 100% 持久化，零闪烁
- 页面不需要任何修改

### 缺点
- 地址栏不会更新（用户看到的始终是 `shell.html`）
- 前进/后退按钮行为异常
- 两个独立 JS 上下文，通信需要 `postMessage`
- iframe 有额外的性能开销
- SEO 不友好

## 方案 B：Fetch + DOM Swap（Turbo-lite，推荐）

在 `nav.js` 中拦截导航点击，用 `fetch` 加载目标页 HTML，提取内容区 DOM，原地替换。

### 架构

```
每个页面统一结构:
┌─ <body> ──────────────────────────────────────┐
│  <aside class="sidebar">  ← 由 nav.js 注入，不刷新 │
│  <div id="view">          ← 内容替换目标         │
│    ...page content...                          │
│  </div>                                       │
└────────────────────────────────────────────────┘
```

### 导航流程

```
1. 用户点击导航链接
2. e.preventDefault() 阻止浏览器跳转
3. fetch(url) → 获取 HTML（命中 `_pageCache` 则跳过）
4. DOMParser 解析 → 提取 `<div id="view">` 内容
5. document.startViewTransition() 包裹（同文档 VT，无卸载）
6. 替换 `<div id="view">` 的 innerHTML
7. history.pushState(url) 更新地址栏
8. 执行目标页初始化脚本 (init)
9. 清理旧页资源 (destroy: ECharts dispose / 定时器)
```

### 关键实现

#### nav.js 核心（~100 行）

```javascript
// 各页面注册的初始化/销毁函数
const _pageHandlers = {};

export function registerPage(key, init, destroy) {
    _pageHandlers[key] = { init, destroy };
}

let _currentPage = null;
const _pageCache = new Map(); // 缓存已加载页面的 HTML

async function navigateTo(href, pushState = true) {
    // 1. 获取页面 HTML（优先缓存）
    let html = _pageCache.get(href);
    if (!html) {
        const resp = await fetch(href);
        html = await resp.text();
        _pageCache.set(href, html);
    }

    // 2. 解析
    const doc = new DOMParser().parseFromString(html, 'text/html');

    // 3. 提取内容
    const newView = doc.querySelector('#view');
    const newTitle = doc.querySelector('title')?.textContent;
    const newStyles = [...doc.querySelectorAll('style')];

    if (!newView) { window.location.href = href; return; }

    // 4. 清理旧页面
    if (_currentPage && _pageHandlers[_currentPage]?.destroy) {
        await _pageHandlers[_currentPage].destroy();
    }

    // 5. 替换 DOM（同文档 VT）
    const update = () => {
        const view = document.getElementById('view');
        view.innerHTML = newView.innerHTML;

        // 替换页面级样式
        document.querySelectorAll('style[data-route]').forEach(s => s.remove());
        newStyles.forEach(s => {
            const clone = document.createElement('style');
            clone.setAttribute('data-route', '');
            clone.textContent = s.textContent;
            document.head.appendChild(clone);
        });

        // 更新标题
        if (newTitle) document.title = newTitle;

        // 重新激活 lucide 图标
        if (typeof lucide !== 'undefined') lucide.createIcons();
    };

    if (document.startViewTransition) {
        await document.startViewTransition(() => update()).finished;
    } else {
        update();
    }

    // 6. 更新 URL
    const pageKey = href.replace('.html', '');
    if (pushState) history.pushState({ page: pageKey }, '', href);
    _currentPage = pageKey;

    // 7. 初始化新页面
    const key = Object.keys(_pageHandlers).find(k => href.includes(k));
    if (key && _pageHandlers[key]?.init) {
        await _pageHandlers[key].init();
    }
}

// 拦截导航栏点击
navEl.addEventListener('click', (e) => {
    const link = e.target.closest('a');
    if (!link) return;
    const href = link.getAttribute('href');
    if (!href || href.startsWith('http') || href.startsWith('#')) return;
    e.preventDefault();
    navigateTo(href);
});

// 处理浏览器前进/后退
window.addEventListener('popstate', (e) => {
    if (e.state?.page) {
        navigateTo(e.state.page + '.html', false);
    }
});
```

#### 每个页面改造（以 index.html 为例，已实施版本）

```html
<!-- index.html -->
<div id="view">
    <!-- 原有内容不变 -->
</div>

<script type="module">
    import { registerPage, initSidebar } from './assets/nav.js';

    // 注册初始化/销毁函数
    registerPage('index',
        async () => {
            // 原有的初始化逻辑
            await loadDashboard();
            renderCharts();
        },
        () => {
            // 清理资源
            chartInstances.forEach(c => c.dispose());
            clearInterval(refreshTimer);
        }
    );

    initSidebar('index');
    // 首次加载时立即初始化
    (async () => {
        await loadDashboard();
        renderCharts();
    })();
</script>
```

### 需要统一的前提条件（已实施版本）

| 前提 | 实际实施 |
|------|--------|
| 每个页面有 `<div id="view">` 作为内容容器 | 各页面已就绪 |
| 侧边栏由 `nav.js` 注入，不在各页面 HTML 中重复 | 由 `initSidebar()` 完成 |
| 初始化逻辑抽取为 init/destroy 函数 | `registerPage(key, init, destroy)` |
| `nav.js` ~180 行实现 | 已完成 |

实际改动量集中在 `nav.js`，各页面改动极少。

### 优点
- 侧边栏 **真正持久化** —— 同一个 DOM 节点永不销毁
- 地址栏正确更新，前进/后退正常工作
- 使用同文档 VT，过渡由 JS 精确控制，无白屏
- 降级优雅：JS 被禁用时退化为普通 `<a>` 跳转
- 被缓存过的页面二次访问为 0ms 渲染（DOM 已在缓存中）

### 缺点
- 每页需要 `<div id="view">` 结构（已统一）
- 页面初始化逻辑需要 `registerPage` 注册
- 需要在 `destroy()` 中正确清理 ECharts 实例和定时器

## 推荐方案与实施路径

### 推荐：方案 B（Fetch + DOM Swap）✅ 已实施

这是 Hotwire Turbo 的核心思想，已在 `nav.js` 中实现为侧边栏 SPA 导航系统：
- 不改后端
- 不改页面视觉
- 侧边栏由 `nav.js` 注入到 `<body>`，不在各页面 HTML 中重复
- `nav.js` 包含导航拦截、fetch、缓存、DOM swap、VT 动画、popstate 处理

### 实施步骤（已完成）

1. **统一页面结构** — 每个页面使用 `<div id="view">` 作为内容容器
2. **nav.js 改造** — `registerPage` / `navigateTo` / click 拦截 / popstate 处理 / `_pageCache`
3. **每个页面改造** — 调用 `registerPage(key, init, destroy)` 和 `initSidebar(current)`
4. **全局 CSS** — 侧边栏样式定义在 `styles-v4.css` 中，使用 `--bg-sidebar` / `--divider` 等变量

- 侧边栏 DOM 节点永不销毁，零闪烁
