# 前端参考图片需求说明

## 为什么需要参考图片

文字描述设计的局限性在于：同一份设计文档，不同人脑中的画面完全不同。你说"温暖的学习伴侣"，我想到的是柔和渐变；你想到的可能是圆润的卡通插画。图片能直接对齐审美预期，让实现结果更接近你心中的样子。

## 图片类型

你需要提供的图片分为三类，按重要性排列：

### 第一类：你想要的（最重要）

**"希望我的系统长这样"的参考截图。** 从你见过的产品中截取。不限于教育类产品，任何你觉得"好看"的界面都可以。

- 每张图说明你喜欢的具体是什么（布局？配色？卡片样式？动画？信息密度？）
- 可以是一句话标注，比如"喜欢这个卡片的阴影和圆角""喜欢这个侧边栏的层级"
- 来源不限：Dribbble、Behance、Pinterest、实际产品截图、Twitter 截图均可

### 第二类：你不想要的

**"我的系统现在像这样，但我不喜欢"的标注截图。** 这是目前系统某个页面的截图，你在上面圈出不满意的地方。

- 圈出具体区域并标注问题（"这里太挤""配色太冷""按钮不显眼"）
- 即使是粗略的手写标注也可以

### 第三类：功能参考（可选）

**"这个功能我想要类似的交互方式"的参考。** 比如某个产品的搜索体验、某个 App 的列表动画、某个网站的卡片 hover 效果。

## 具体需求清单

### 类别 A：整体风格参考（3-5 张）

**说明你要什么风格基调。** 给出你觉得"好看"的产品截图。

| 编号 | 内容 | 为什么需要 |
|------|------|-----------|
| A1 | 你喜欢的 **仪表盘/数据看板** 截图 | 确定首页的布局密度、卡片风格、数据展示方式 |
| A2 | 你喜欢的 **对话/聊天界面** 截图 | 确定聊天页的气泡样式、输入区设计、侧边栏风格 |
| A3 | 你喜欢的 **列表/卡片列表** 截图 | 确定资源库、学习路径等列表页的信息排布 |
| A4 | 你喜欢的 **表单/设置页** 截图 | 确定生成配置、个人画像等表单页的风格 |
| A5 | 你喜欢的 **暗色/深色模式** 截图（可选） | 如果知识图谱等页面想做暗色主题 |

每张图请附带一句话说明你喜欢什么。例如：
> "喜欢 Notion 的侧边栏——简洁、有图标+文字、选中态是浅色背景而非反色"

### 类别 B：关键页面改造参考（每个核心页面 1-2 张）

**说明每个页面你希望做成什么样。**

| 编号 | 目标页面 | 当前问题 | 需要的参考 |
|------|---------|---------|-----------|
| B1 | 学习看板 (index) | 单调的统计卡片 + 时间线 | 你想要的首页/仪表盘风格 |
| B2 | 智能对话 (chat) | 气泡样式、推荐面板、会话列表 | 你想要的聊天界面风格 |
| B3 | 资源生成 (generate) | 表单配置 + 进度展示 + 结果展示 | 你想要的"工具配置页"风格 |
| B4 | 资源库 (library) | 资源列表 + 筛选 + 预览弹窗 | 你想要的文件/资源管理风格 |
| B5 | 学习路径 (pathway) | 知识图谱 + 路径卡片 + 学习记录 | 你想要的图谱/路径展示风格 |
| B6 | 学习评估 (evaluate) | 答题界面 + 成绩单 | 你想要的测验/考试界面风格 |
| B7 | 个人中心 (profile) | 画像表单 + 分析图表 | 你想要的个人设置/数据看板风格 |

### 类别 C：组件级细节参考（5-8 张）

**说明具体 UI 元素你希望做成什么样。** 如果没有特别偏好，可以跳过。

| 编号 | 组件 | 为什么需要 |
|------|------|-----------|
| C1 | 你喜欢的**按钮样式** | 确定主按钮/次按钮/危险按钮的视觉风格 |
| C2 | 你喜欢的**卡片样式** | 确定卡片的圆角、阴影、边框、内边距 |
| C3 | 你喜欢的**空状态插画** | 确定"暂无数据"页面的视觉风格 |
| C4 | 你喜欢的**加载动画** | 确定 loading/skeleton 的表现形式 |
| C5 | 你喜欢的**侧边栏/导航** | 确定导航的结构和视觉层次 |
| C6 | 你喜欢的**标签/徽章** | 确定状态标签的样式（进行中/已完成等） |
| C7 | 你喜欢的**弹窗/对话框** | 确定模态框的风格 |
| C8 | 你喜欢的**Toast/通知** | 确定通知的样式和位置 |

## 图片规格要求

| 属性 | 要求 |
|------|------|
| 格式 | PNG 或 JPG 均可 |
| 分辨率 | 不需要高清原图，能看清界面布局即可（建议宽度 ≥ 800px） |
| 来源 | 截图、设计稿、手绘线框图、从设计网站下载的图片均可 |
| 标注 | **不强求**，但如果你能在图上画圈/箭头指出关键点会大幅提升效率 |
| 命名 | 建议用英文或拼音命名，如 `dashboard-ref-01.png`、`chat-style.png` |

## 最少可行方案

如果你时间有限，**最少只需要 3-5 张图片**：

1. **一张你喜欢的仪表盘**（确定整体风格基调）
2. **一张你喜欢的聊天界面**（chat 是核心页面）
3. **一张你喜欢的列表/卡片页**（确定资源库风格）
4. **一张你觉得"不好看"的当前页面截图**（标注哪里不满意）
5. **一张你心目中"理想的学习产品"截图**（如果有一款产品你觉得"就应该是这样"）

有了这 3-5 张图，我就能基本对齐你的审美方向。

## 补充说明

### 没有参考图怎么办

如果你手头没有现成的参考图，以下替代方案同样有效：

| 替代方式 | 示例 |
|---------|------|
| 说出你觉得好看的产品名 | "像 Notion 那样简洁" "像 Linear 那样现代" "像 Duolingo 那样活泼" |
| 给出一个形容词范围 | "专业但不要太企业软件" "年轻但不幼稚" "技术感但不冰冷" |
| 描述一个场景感受 | "打开页面像翻开一本精装书" "像是在用 Apple 原生应用" |
| 否定式描述 | "不要像企业后台管理系统" "不要太花哨的渐变色" "不要纯平的扁平设计" |

### 我能看到的

我可以通过以下方式查看你提供的图片：
- 你直接告诉我电脑上的图片文件路径，我直接读取
- 你把图片放在项目目录下（如 `docs/xqt/front/refs/`），告诉我路径
- 你把图片拖到对话框里
