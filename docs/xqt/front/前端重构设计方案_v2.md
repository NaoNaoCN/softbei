# 前端设计重构方案 v2 —— 基于参考素材提炼

## 零、参考素材分析

从 `frontend/temp/` 下 6 份设计素材提炼出的共同设计语言：

### 色彩倾向
| 特征 | 素材中的表现 | 对应方向 |
|------|-------------|---------|
| 主色调 | 紫色系（`#purple-400→#purple-600`、`#5f29c7`） | 当前蓝紫渐变方向正确，需强化紫色比重 |
| 暗色表面 | `#343434`、`#292524`、深色背景多处出现 | 关键区域可用暗色背景制造"沉浸感" |
| 阴影 | 带色相的有色阴影（`shadow-purple-200/50`） | 阴影不应是纯灰黑的，应带主色调 |
| 对比 | 白底卡片配紫色阴影，暗底配白色元素 | 亮暗交替制造视觉节奏 |

### 形状倾向
| 特征 | 素材中的表现 | 对应方向 |
|------|-------------|---------|
| 圆角 | 全圆角（`rounded-full`）、20px、10px 高频出现 | 当前 8-16px 不够圆，应提升到 12-20px |
| 按钮 | 胶囊形（`rounded-full`）或大圆角 | sidebar 项、标签、主按钮都应走胶囊形 |
| 输入框 | 与按钮融合在同一容器内（无边框输入 + 外侧圆角容器） | 搜索框、对话输入等应走"内嵌按钮"模式 |

### 动画倾向
| 特征 | 素材中的表现 | 对应方向 |
|------|-------------|---------|
| 弹性 | `bounceFadeIn`、`jello-vertical`、`cubic-bezier` 弹性曲线 | 交互反馈要有"弹跳感"，不能只是线性过渡 |
| 错位 | loader 的 `nth-child` 延迟动画 | 列表、卡片入场要有 staggered 时序 |
| 按压 | `:active` 时 `scale(0.9)` | 所有按钮都要有按压缩放反馈 |

### 装饰倾向
| 特征 | 素材中的表现 | 对应方向 |
|------|-------------|---------|
| 网格线图案 | 渐变背景上叠加 grid-line mask 图案 | 知识图谱、首页 hero 可用图案装饰 |
| 彩色阴影 | `shadow-purple-200/50` | 卡片投影带紫色调 |
| 过渡色 | `bg-gradient-to-r from-purple-400 to-purple-600` | 渐变不只是按钮，选中态、标签也要用 |

## 一、设计系统升级

### 1.1 色彩体系 v2

保留原方案的蓝紫渐变基础，增加暗色表面和色相阴影：

```
主色渐变:    #4F6EF7 → #7C5CFC          (保持不变，但紫色端延伸到 #A78BFA)
辅色渐变:    #0ea5e9 → #8b5cf6          (新增：更鲜艳的蓝紫，用于装饰)
暗色表面:    #1E1E2E / #2D2A3E          (新增：卡片暗面、代码区、图谱区)
亮色表面:    #FFFFFF                     (卡片主体)
背景层:      #F5F3FA                     (比当前 #F7F8FC 更偏紫灰)
紫色阴影:    rgba(124,92,252,0.12)      (替代灰色阴影)
紫色强阴影:  rgba(124,92,252,0.25)      (悬浮卡片)
蓝色阴影:    rgba(79,110,247,0.15)      (统计卡片)
```

**关键变化**：所有阴影都带紫色/蓝色色相，不再使用 `rgba(0,0,0,x)` 的纯黑灰色阴影。

### 1.2 圆角规范 v2

| 元素 | 当前值 | 新值 | 原因 |
|------|-------|------|------|
| 按钮 | 10px | 12-14px | 向胶囊形靠拢 |
| 侧边栏导航项 | 8px | 25px (full) | 参考素材中的 rounded-full |
| 卡片 | 12-16px | 18-20px | 增加柔和感 |
| 输入框 | 8px | 14px | 配合按钮圆角 |
| 标签/徽章 | 6px | 12px (full) | 胶囊形 |
| Toast | 12px | 16px | 更柔和 |
| 弹窗 | 16px | 22px | 更接近"卡片"感受 |

### 1.3 阴影规范 v2

```css
/* 卡片悬浮阴影 — 带紫色色相 */
--shadow-card: 0 2px 16px rgba(124,92,252,0.08), 0 1px 3px rgba(0,0,0,0.02);

/* 卡片悬浮加强 — 更深紫色 */
--shadow-card-hover: 0 8px 30px rgba(124,92,252,0.15), 0 2px 6px rgba(0,0,0,0.04);

/* 按钮阴影 — 带主色 */
--shadow-button: 0 4px 14px rgba(79,110,247,0.25);

/* 弹窗/Modal — 大扩散 */
--shadow-modal: 0 16px 60px rgba(124,92,252,0.18), 0 4px 12px rgba(0,0,0,0.06);

/* 暗色卡片 — 紫色光晕 */
--shadow-dark-card: 0 0 40px rgba(139,92,246,0.15), 0 4px 12px rgba(0,0,0,0.3);

/* 无灰色阴影 — 一切阴影都带色彩倾向 */
```

### 1.4 动画体系 v2

```css
/* 弹性入场 — 替代线性 fadeIn */
@keyframes bounceIn {
  0%   { transform: scale(0.9); opacity: 0; }
  60%  { transform: scale(1.03); }
  80%  { transform: scale(0.98); }
  100% { transform: scale(1); opacity: 1; }
}

/* 按钮按压反馈 */
.btn:active { transform: scale(0.94); transition: transform 0.1s; }

/* 列表错位入场 */
@keyframes staggerFadeIn {
  from { transform: translateY(12px); opacity: 0; }
  to   { transform: translateY(0); opacity: 1; }
}
.stagger-item:nth-child(1) { animation-delay: 0.00s; }
.stagger-item:nth-child(2) { animation-delay: 0.06s; }
.stagger-item:nth-child(3) { animation-delay: 0.12s; }
/* ...依次递推 */

/* 加载动画 — 跳动条 */
@keyframes loaderBounce {
  0%, 100% { transform: scaleY(1); }
  50%      { transform: scaleY(2.5); }
}
/* n 个 bar，animation-delay 依次偏移 0.15s */

/* 选中态弹性过渡 */
.form-radio.selected {
  transition: all 0.3s cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

### 1.5 装饰元素

**网格线背景图案**（用于知识图谱页、首页 hero 区）：

```css
.grid-pattern-bg {

```

**光晕装饰**（用于卡片右上角、标题旁边）：

```css
  pointer-events: none;

.glow-orb.purple { background: #7C5CFC; width: 200px; height: 200px; }
.glow-orb.blue   { background: #4F6EF7; width: 160px; height: 160px; }
```

## 五、与 v1 方案的差异总结

| 维度 | v1 方案 | v2 方案 |
|------|--------|--------|
| 侧边栏 | 浅色背景 + 方块选中 | **暗色背景 + 胶囊形选中** |
| 阴影 | 纯灰色 `rgba(0,0,0,x)` | **紫色色相阴影** |
| 圆角 | 8-16px | **12-25px（胶囊形）** |
| 动画 | 线性过渡 | **弹性曲线 + 错位入场 + 按压缩放** |
| 按钮 | 渐变方块 | **全宽胶囊形 + 按压缩放反馈** |
| 选择器 | 传统 checkbox/radio | **胶囊形多选（选中态紫色渐变）** |
| 输入框 | 独立边框输入框 | **内嵌按钮的一体化输入组** |
| 装饰 | 纯色渐变光晕 | **网格线图案 + 紫色光晕 + 暗色调区域** |
| 整体印象 | 干净但平淡 | 有性格、有色彩、有质感 |
