# 163 邮箱 SMTP 配置指南

## 1. 获取 163 邮箱授权码

163 邮箱的 SMTP 密码必须使用**授权码**，而非邮箱登录密码。

**步骤：**

1. 登录 [163 邮箱](https://mail.163.com)
2. 点击页面上方的 **设置** → **POP3/SMTP/IMAP**
3. 找到 **SMTP 服务**，点击 **开启**
4. 按照页面提示发送短信验证（发送到你的绑定手机号）
5. 验证通过后，系统会生成一个 **16 位授权码**（形如 `ABCDEFGHIJKLMNOP`）
6. 复制并保存该授权码，页面关闭后将无法再次查看

> 如果之前已开启过 SMTP 服务，授权码丢失需先关闭再重新开启以获取新授权码。

## 2. 配置 .env 文件

在项目根目录的 `.env` 文件中，修改 SMTP 配置段：

```bash
# ============================================================
# SMTP 邮件服务配置
# ============================================================
SMTP_HOST=smtp.163.com
SMTP_PORT=465
SMTP_USERNAME=your_email@163.com
SMTP_PASSWORD=你的16位授权码
SMTP_FROM=学习系统 <your_email@163.com>
SMTP_USE_TLS=true
SMTP_TIMEOUT=30
EMAIL_MAX_RETRIES=3
EMAIL_VERIFY_EXPIRE_MINUTES=30
EMAIL_PASSWORD_RESET_EXPIRE_MINUTES=15
EMAIL_RATE_LIMIT_PER_HOUR=5
```

**填写说明：**

| 参数 | 值 | 说明 |
|------|-----|------|
| `SMTP_HOST` | `smtp.163.com` | 163 邮箱 SMTP 服务器地址 |
| `SMTP_PORT` | `465` | 163 使用 SSL 端口 465 |
| `SMTP_USERNAME` | `your_email@163.com` | 你的完整 163 邮箱地址 |
| `SMTP_PASSWORD` | 16位授权码 | 第 1 步获取的授权码，不是邮箱登录密码 |
| `SMTP_FROM` | `学习系统 <your_email@163.com>` | 发件人显示名和地址，地址须与 SMTP_USERNAME 一致 |
| `SMTP_USE_TLS` | `true` | 163 端口 465 使用隐式 TLS |

## 3. 验证配置

### 3.1 检查配置是否生效

```bash
python -c "from backend.config import config; print('host:', config.email.smtp_host); print('enabled:', bool(config.email.smtp_host and config.email.smtp_password))"
```

如果 `enabled: True`，说明配置已生效，邮件将通过 SMTP 真实发送。如果 `enabled: False`，系统会降级为 debug 模式（邮件保存到本地 `debug_emails/` 目录）。

### 3.2 运行测试

```bash
python test_email.py
```

测试脚本会执行注册 → 登录 → 发送验证邮件 → 忘记密码 → 重置密码 → 发送学习报告的完整流程。如果 SMTP 配置正确，对应的邮件会真实发送到邮箱。

### 3.3 端到端测试

启动服务后访问 `http://localhost:8000/app/auth.html`，使用带邮箱的方式注册一个新用户，检查 163 邮箱是否收到验证邮件。

## 4. 常见问题

**Q: 提示 `authentication failed` 或 `535` 错误**

A: `SMTP_PASSWORD` 填的不是登录密码，是授权码。请检查第 1 步是否正确获取了 16 位授权码。

**Q: 提示 `connection timed out`**

A: 检查网络是否能访问 `smtp.163.com`，某些网络环境（校园网、公司内网）可能封锁了 SMTP 端口。

**Q: 收不到邮件**

A: 检查邮箱的垃圾箱。首次发送的邮件可能被误判为垃圾邮件，将发件人加入白名单即可。

**Q: 想先用 debug 模式不真实发邮件**

A: 将 `.env` 中 `SMTP_HOST=` 和 `SMTP_PASSWORD=` 留空即可。系统会自动将邮件保存为 HTML 文件到 `debug_emails/` 目录，可用浏览器直接打开查看。

## 5. 其他邮件服务商参考

| 服务商 | SMTP_HOST | SMTP_PORT |
|--------|-----------|-----------|
| QQ邮箱 | `smtp.qq.com` | 587 |
| 126邮箱 | `smtp.126.com` | 465 |
| 阿里云邮箱 | `smtp.aliyun.com` | 465 |
| Gmail | `smtp.gmail.com` | 587 |
| Outlook | `smtp-mail.outlook.com` | 587 |

> 不同服务商的端口和 TLS 模式不同：端口 465 通常使用隐式 TLS（`SMTP_USE_TLS=true`），端口 587 通常使用 STARTTLS（需确认 `aiosmtplib` 参数匹配）。当前代码统一使用 `use_tls` 参数，适配 163 的 465 端口，如需使用其他服务商的 587 端口，需将 `sender.py` 中的 `use_tls` 改为 `start_tls`。
