# RAG 元数据增强 — 改动说明

> 日期：2026-05-21 | 基于 `docs/design/rag/RAG_ENHANCEMENT_ANALYSIS.md` Phase 1 实施

## 1. 改动概要

为 `document_chunk` 表新增 `metadata` JSONB 列，打通"索引时写入元数据 → 检索时返回元数据"的完整链路，为后续按元数据过滤检索（如按内容类型、难度、语言筛选）奠定基础。

## 2. 改动文件清单

| 文件 | 改动类型 | 说明 |
|------|----------|------|
| `backend/db/models.py` | 新增列 | `DocumentChunk` 增加 `metadata_` 列（JSONB） |
| `migrations/versions/5d8e1f2a3b4c_*.py` | 新增 migration | 添加 `metadata` JSONB 列及 GIN 索引 |
| `backend/db/vector.py` | 5 处改动 | 读写链路全线接入 metadata |
| `backend/rag/indexer.py` | 1 处改动 | 将 `TextChunk.metadata` 透传入库 |
| `backend/rag/retriever.py` | 3 处改动 | `RetrievedChunk` 增加 `metadata` 字段 |
| `backend/rag/loader.py` | 2 处改动 | 自动检测语言、提取课程名 |

## 3. 详细改动

### 3.1 ORM 模型 (`backend/db/models.py:161`)

```python
# 新增
from sqlalchemy.dialects.postgresql import JSONB

# DocumentChunk 新增列
metadata_: Mapped[dict | None] = mapped_column("metadata", JSONB, default=dict)
```

- 列名为 `metadata`（PostgreSQL 保留字，故 ORM 属性名加 `_` 后缀）
- 类型为 JSONB，支持 GIN 索引加速内部字段查询
- 默认值 `{}`

### 3.2 数据库迁移 (`migrations/versions/5d8e1f2a3b4c_*.py`)

```sql
-- upgrade
ALTER TABLE document_chunk ADD COLUMN metadata JSONB;
CREATE INDEX ix_document_chunk_metadata ON document_chunk USING GIN (metadata);

-- downgrade
DROP INDEX ix_document_chunk_metadata;
ALTER TABLE document_chunk DROP COLUMN metadata;
```

上一个 migration: `107bc3a0d271` (user_id index)

### 3.3 向量存储层 (`backend/db/vector.py`)

**`_convert_metadata_to_columns`** — 核心逻辑：

```python
# 将 metadata dict 拆分为固定列字段 + JSONB extra 字段
extra_meta = {k: v for k, v in meta.items()
              if k not in ("source", "page", "section", "user_id", "doc_id", "chunk_id")}
# → {"metadata_": '{"language": "zh", "chunk_type": "definition"}'}
```

- 固定列字段（`source`, `page`, `section`, `user_id`）直接写入对应列
- 其余字段序列化为 JSON 字符串存入 `metadata` 列
- `doc_id` 和 `chunk_id` 被排除（它们有独立逻辑处理）

**`upsert_documents`** — INSERT/UPSERT 增加 `metadata` 列

**`query_documents`** — SELECT 增加 `metadata` 列，结果中合并 JSONB 字段到 meta dict

**`get_documents_by_doc_id`** — 同上

**`_CollectionProxy.get`** — 同上

### 3.5 检索层 (`backend/rag/retriever.py`)

**`RetrievedChunk`** 新增字段：

```python
metadata: dict = field(default_factory=dict)  # 扩展元数据（JSONB）
```

**`_parse_results`** — 从原始 meta dict 中提取扩展元数据（排除固定键 `doc_id`, `source`, `page`, `section`, `user_id`）

**`format_context`** — 在引用行展示元数据：

```
[1] （来源：chapter_01.pdf，第 2 页，第三章 [定义, 中文, 入门]）
梯度下降是一种...
```

展示规则：
- `chunk_type` → 中文标签（定义/定理/示例/习题/总结）
- `language` → 中文标签（中文/英文/中英混合）
- `difficulty` → 中文标签（入门/进阶/高级）

### 3.6 文档加载层 (`backend/rag/loader.py`)

**`_parse_markdown_to_chunks`** — 每个 chunk 自动填充：

| 元数据字段 | 值 | 来源 |
|-----------|-----|------|
| `language` | `zh` / `en` / `mixed` | 字符比例自动检测（中文 > 75% → zh，英文 > 75% → en，其余 → mixed） |
| `course` | 父目录名 | 从文件路径自动提取 |

**`_detect_language(text)`** — 新增辅助函数，统计中英文字符比例。

## 4. 数据流示意

```
文档上传
  → loader.load_file()
    → _parse_markdown_to_chunks()
      → _detect_language()           auto: language
      → course from path             auto: course
      → TextChunk(metadata={...})
  → indexer.index_chunks()
    → upsert_documents(metadatas=[{..., **c.metadata}])
      → _convert_metadata_to_columns()
        → fixed columns: source, page, section, user_id
        → JSONB metadata: language, course, (chunk_type, difficulty, ...)
      → INSERT INTO document_chunk (..., metadata)

检索
  → retriever.retrieve()
    → query_documents()              SELECT ... metadata FROM document_chunk
    → _parse_results()
      → RetrievedChunk(metadata={language: "zh", course: "ai_intro", ...})
  → format_context()
    → "[1] (来源: ai_intro.pdf [中文]) ..."
```

---

## 5. 向后兼容

- `metadata` 列允许 NULL，旧数据不受影响
- 检索时若 `metadata` 为空，`RetrievedChunk.metadata` 返回空 `{}`
- 索引时若 `TextChunk.metadata` 为空，存入的 JSONB 为 `NULL`
- `_CollectionProxy.get()` 和 `query_documents()` 的返回结构中，metadata 字段被合并到原有 meta dict 的顶层，调用方按原有 key 访问不受影响
