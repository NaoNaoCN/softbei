1. 总体数据流（索引 + 检索两阶段）

6. 向量检索路径（retrieve）— 单路语义检索

始终生效的默认路径。预取 3x 候选，经过 re-rank 和父块回填后截断到 Top-5。

7. 关键词检索路径（retrieve_keyword）— tsvector + jieba

混合检索启用时作为第二路并行执行。词级精确匹配（"学习"不会误匹配"学生"），GIN 索引加速。

9. 父块回填（_resolve_parent_chunks）— 算法详解

对所有检索路径生效。将精确匹配的小子块替换为上下文更完整的大父块，同一父块的多个子块只保留最高分。

pid = c.metadata.get('parent_chunk_id')
if pid: child_to_parent[c.chunk_id] = pid"] S1 --> CHECK{"有 parent_chunk_id?"} CHECK -->|"无"| PASS["返回原始 chunks
（向后兼容旧数据）"] CHECK -->|"有"| S2["Step 2: 批量查询父块文本
SELECT chunk_id, text
FROM document_chunk
WHERE chunk_id = ANY(parent_ids)
AND is_parent = TRUE"] S2 --> S3["Step 3: 去重 + 回填
seen_parents = set()"] S3 --> LOOP["遍历 chunks（已按 score 降序）"] LOOP --> DUP{"同一 parent_chunk_id
已出现过？"} DUP -->|"是（低分子块）"| SKIP["跳过（去重）"] DUP -->|"否（最高分子块）"| FILL["用父块 text 替换子块 text
