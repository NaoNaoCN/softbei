## 附：核心创新点专章设计

> 评审专家明确要求创新点只保留三个，每个 1-2 页深入讲解。

### 创新点一：教材驱动的可控知识库与多模态解析管道
- 问题：通用 LLM 在垂直课程上幻觉严重
- 方案：教材上传 → 多格式解析 → 父-子分块 → 向量+全文索引 → 检索生成
- 亮点：多格式结构保留、pgvector+tsvector 混合、自动索引
- 效果：黄金数据集 P@5 显著提升，引用准确率 90%+

### 创新点二：垂直领域模型基座引擎
- 问题：多模型、多工具散落在业务代码中，难以维护
- 方案：将 LLM/Embedding/RAG/工具调用打包为基座引擎
- 亮点：Provider 抽象、提示词外置、异常自动降级、与上层解耦
- 价值：新 Agent 接入只需调用基座 API

### 创新点三：基于 LangGraph 的多智能体调度中枢
- 问题：多智能体分散调用，状态难管理
- 方案：以 LangGraph 状态机为中枢，11 节点协同
- 亮点：集中式 AgentState、条件路由、DB 会话注入、新 Agent 标准化接入
- 价值：业务逻辑与编排解耦
