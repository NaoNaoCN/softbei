# CRUD - 数据库基础增删改查封装

## 概述

`crud.py` 提供了一套通用的异步 CRUD（Create/Read/Update/Delete）操作封装，基于 SQLAlchemy 异步会话实现。所有函数都是泛型函数，可适用于任何 ORM 模型。

## 设计理念

1. **通用性**：通过 `TypeVar` 泛型，支持任意 ORM 模型
2. **简洁性**：提供最常用的操作，无需编写 SQL
3. **灵活性**：支持条件过滤、排序、分页、关系预加载
4. **异步**：所有操作均为异步，支持高并发

## 泛型类型

```python
ModelT = TypeVar("ModelT")
```

所有 CRUD 函数都接受 `model: type[ModelT]` 参数，返回 `ModelT` 或 `Sequence[ModelT]` 类型。

## 函数详解

### 1. insert - 单条插入

```python
async def insert(
    session: AsyncSession,
    model: type[ModelT],
    data: dict[str, Any],
    commit: bool = True,
) -> ModelT
```

**功能**：插入单条记录。

**参数**：
| 参数 | 类型 | 说明 |
|——|——|——|
| session | AsyncSession | 数据库会话 |
| model | type[ModelT] | ORM 模型类 |
| data | dict[str, Any] | 要插入的字段数据 |
| commit | bool | 是否立即提交，默认 True |

**返回**：新创建的模型实例

**使用示例**：

```python
new_user = await insert(
    session,
    User,
    {"username": "alice", "hashed_password": "xxx"}
)
```

---

### 2. insert_many - 批量插入

```python
async def insert_many(
    session: AsyncSession,
    model: type[ModelT],
    data_list: list[dict[str, Any]],
    commit: bool = True,
) -> list[ModelT]
```

**功能**：批量插入多条记录。

**使用示例**：

```python
# 批量创建题目
questions = await insert_many(
    session,
    QuizItem,
    [
        {"stem": "题1", "answer": "A", ...},
        {"stem": "题2", "answer": "B", ...},
    ]
)
```

---

### 3. select - 列表查询

```python
async def select(
    session: AsyncSession,
    model: type[ModelT],
    filters: dict[str, Any] | None = None,
    order_by: Any | None = None,
    limit: int | None = None,
    offset: int | None = None,
    loadRelations: list[str] | None = None,
) -> Sequence[ModelT]
```

**功能**：查询记录列表，支持过滤、排序、分页、关系预加载。

**参数**：
| 参数 | 类型 | 说明 |
|——|——|——|
| filters | dict[str, Any] | None | 过滤条件，键为字段名，值为过滤值 |
| order_by | Any | None | 排序字段，如 `User.username` 或 `desc(User.id)` |
| limit | int | None | 返回条数限制 |
| offset | int | None | 跳过条数（分页） |
| loadRelations | list[str] | None | 预加载的关系属性名 |

**过滤规则**：
- `value is None` → `field IS NULL`
- `value is not None` → `field == value`

**使用示例**：

```python
# 查询用户列表，按创建时间倒序
users = await select(
    session,
    User,
    filters={"username": "alice"},
    order_by=desc(User.created_at),
    limit=10
)

# 预加载关系
sessions = await select(
    session,
    ChatSession,
    filters={"user_id": user_id},
    loadRelations=["messages"]
)
```

### 4. select_one - 单条查询

```python
async def select_one(
    session: AsyncSession,
    model: type[ModelT],
    filters: dict[str, Any] | None = None,
    loadRelations: list[str] | None = None,
) -> ModelT | None
```

**功能**：查询单条记录（LIMIT 1）。

**使用示例**：

```python
profile = await select_one(
    session,
    StudentProfile,
    filters={"user_id": user_id}

```

### 5. select_by_id - 按主键查询

```python
async def select_by_id(
    session: AsyncSession,
    model: type[ModelT],
    id: Any,
    loadRelations: list[str] | None = None,

```

**功能**：根据主键 ID 查询单条记录。

**使用示例**：

### 6. count - 统计数量

```python
async def count(
    session: AsyncSession,
    model: type[ModelT],
    filters: dict[str, Any] | None = None,
) -> int
```

**功能**：统计符合条件的记录数量。

**使用示例**：

```python
total = await count(session, User, filters={"username": like("a%")})
```

---

### 7. update - 条件更新

```python
async def update_(
    session: AsyncSession,
    model: type[ModelT],
    filters: dict[str, Any],
    data: dict[str, Any],
    commit: bool = True,
) -> int
```

**功能**：更新符合条件的记录。

**返回**：实际更新的记录数

**使用示例**：

```python
rows = await update_(
    session,
    User,
    filters={"id": user_id},
    data={"username": "new_name"}
)
```

---

### 8. update_by_id - 按主键更新

```python
async def update_by_id(
    session: AsyncSession,
    model: type[ModelT],
    id: Any,
    data: dict[str, Any],
    commit: bool = True,
) -> bool
```

**功能**：根据主键 ID 更新记录。

**返回**：是否更新了记录

**使用示例**：



**功能**：删除符合条件的记录。


**功能**：根据主键 ID 删除记录。

## 关系预加载

使用 `loadRelations` 参数可以在查询时预加载关系，避免 N+1 查询问题：

```python
# 不使用预加载：N+1 查询
sessions = await select(session, ChatSession, filters={"user_id": user_id})
for session in sessions:
    print(session.messages)  # 每次访问都会触发新查询

# 使用预加载：只需 2 次查询
sessions = await select(
    session, ChatSession,
    filters={"user_id": user_id},
    loadRelations=["messages"]
)
for session in sessions:
    print(session.messages)  # 使用已加载的数据
```

## 过滤条件详解

```python
# 精确匹配
filters = {"username": "alice"}

# NULL 查询
filters = {"email": None}  # email IS NULL

# 多条件（AND 关系）
filters = {"user_id": user_id, "resource_type": "doc"}
```
