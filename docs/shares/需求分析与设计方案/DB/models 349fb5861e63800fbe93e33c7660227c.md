# Models - SQLAlchemy ORM 模型定义

## 概述

`models.py` 定义了 13 张数据库表的 ORM 模型，采用 SQLAlchemy 2.x 的 `Mapped` 类型注解风格。所有模型继承自 `Base`，模块导入后自动注册到 `Base.metadata`。

## 模型总览

| 模型 | 表名 | 说明 |
| --- | --- | --- |
| User | user | 用户账户 |
| StudentProfile | student_profile | 学生画像 |
| ProfileHistory | profile_history | 画像历史快照 |
| ChatSession | chat_session | 对话会话 |
| ChatMessage | chat_message | 消息记录 |
| KGNode | kg_node | 知识图谱节点 |
| KGEdge | kg_edge | 知识图谱边 |
| ResourceMeta | resource_meta | 学习资源元数据 |
| GenerationTask | generation_task | 资源生成任务 |
| QuizItem | quiz_item | 测验题目 |
| QuizAttempt | quiz_attempt | 答题记录 |
| LearningPath | learning_path | 学习路径 |
| LearningPathItem | learning_path_item | 路径中的知识点 |
| LearningRecord | learning_record | 学习记录 |

## 模型详解

### 1. User - 用户账户

```python
class User(Base):
    __tablename__ = "user"

    id: Mapped[uuid.UUID] = mapped_column(primary_key=True, default=uuid.uuid4)
    username: Mapped[str] = mapped_column(String(64), unique=True, nullable=False)
    hashed_password: Mapped[str] = mapped_column(String(128), nullable=False)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)
```

**字段说明**：

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | UUID | 主键 | 用户唯一标识 |
| username | VARCHAR(64) | 唯一 | 用户名 |
| hashed_password | VARCHAR(128) | 非空 | 密码哈希值 |
| created_at | DATETIME | 默认当前 | 创建时间 |

**关系**：
- `profile`: 一对一关系（`StudentProfile`）
- `sessions`: 一对多关系（`ChatSession`）
- `resources`: 一对多关系（`ResourceMeta`）
- `learning_paths`: 一对多关系（`LearningPath`）
- `learning_records`: 一对多关系（`LearningRecord`）

### 2. StudentProfile - 学生画像

```python
class StudentProfile(Base):
    __tablename__ = "student_profile"

    id: Mapped[uuid.UUID] = mapped_column(primary_key=True, default=uuid.uuid4)
    user_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("user.id"), unique=True, nullable=False)
    major: Mapped[str | None] = mapped_column(String(128))
    learning_goal: Mapped[str | None] = mapped_column(Text)
    cognitive_style: Mapped[str | None] = mapped_column(Enum(CognitiveStyle, ...))
    daily_time_minutes: Mapped[int | None] = mapped_column(Integer)
    knowledge_mastered: Mapped[list | None] = mapped_column(JSON)
    knowledge_weak: Mapped[list | None] = mapped_column(JSON)
    error_prone: Mapped[list | None] = mapped_column(JSON)
    current_progress: Mapped[str | None] = mapped_column(Text)
    updated_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
```

**字段说明**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| major | VARCHAR(128) | 学生专业 |
| learning_goal | TEXT | 学习目标描述 |
| cognitive_style | ENUM | 认知风格（visual/text/practice） |
| daily_time_minutes | INT | 每日学习时间（分钟） |
| knowledge_mastered | JSON | 已掌握知识点列表 |
| knowledge_weak | JSON | 薄弱知识点列表 |
| error_prone | JSON | 易错知识点列表 |
| current_progress | TEXT | 当前学习进度 |

**关系**：
- `user`: 多对一关系（`User`）
- `history`: 一对多关系（`ProfileHistory`）

### 6. KGNode - 知识图谱节点

```python
class KGNode(Base):
    __tablename__ = "kg_node"

    id: Mapped[str] = mapped_column(String(64), primary_key=True)   # e.g. "kp_03_01"
    name: Mapped[str] = mapped_column(String(256), nullable=False)
    node_type: Mapped[str] = mapped_column(Enum(KGNodeType, ...), nullable=False)
    description: Mapped[str | None] = mapped_column(Text)
    course_id: Mapped[str | None] = mapped_column(String(64))
```

**字段说明**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | VARCHAR(64) | 节点 ID（如 “kp_03_01”） |
| name | VARCHAR(256) | 节点名称 |
| node_type | ENUM | 节点类型（Course/Chapter/KnowledgePoint/SubPoint/Concept） |
| description | TEXT | 节点描述 |
| course_id | VARCHAR(64) | 所属课程 ID |

**关系**：
- `out_edges`: 一对多关系（作为 source 的边）
- `in_edges`: 一对多关系（作为 target 的边）

### 7. KGEdge - 知识图谱边

```python
class KGEdge(Base):
    __tablename__ = "kg_edge"
    __table_args__ = (UniqueConstraint("source_id", "target_id", "relation"),)

    id: Mapped[uuid.UUID] = mapped_column(primary_key=True, default=uuid.uuid4)
    source_id: Mapped[str] = mapped_column(ForeignKey("kg_node.id"), nullable=False)
    target_id: Mapped[str] = mapped_column(ForeignKey("kg_node.id"), nullable=False)
    relation: Mapped[str] = mapped_column(Enum(KGRelation, ...), nullable=False)
```

**关系类型**：

| 枚举值 | 说明 |
| --- | --- |
| IS_PART_OF | 属于关系（如章节属于课程） |
| REQUIRES | 前置关系（如学习 A 必须先学 B） |
| RELATED_TO | 相关关系（如知识点关联） |
| CONTAINS | 包含关系（如课程包含章节） |

### 8. ResourceMeta - 学习资源

class ResourceMeta(Base):

### 9. GenerationTask - 资源生成任务

```python
class GenerationTask(Base):
    __tablename__ = "generation_task"

    id: Mapped[uuid.UUID] = mapped_column(primary_key=True, default=uuid.uuid4)
    resource_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("resource_meta.id"), unique=True, nullable=False)
    status: Mapped[str] = mapped_column(Enum(TaskStatus, ...), default=TaskStatus.pending, nullable=False)
    progress: Mapped[int] = mapped_column(Integer, default=0)   # 0-100
    error_message: Mapped[str | None] = mapped_column(Text)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)
    updated_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
```

**任务状态枚举**：

| 值 | 说明 |
| --- | --- |
| pending | 等待执行 |
| running | 执行中 |
| done | 已完成 |
| failed | 执行失败 |

## 枚举类型来源

模型中使用的枚举类型（如 `CognitiveStyle`、`KGNodeType` 等）来自 `backend.models.schemas`，确保 Pydantic 模型和 SQLAlchemy 模型使用相同的枚举定义。
