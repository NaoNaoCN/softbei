## 表结构概览

### 1. 用户与画像

- `user` - 用户账户
- `student_profile` - 学生画像（含 JSON 字段存储知识点列表）
- `profile_history` - 画像历史快照

### 2. 对话

- `chat_session` - 会话
- `chat_message` - 消息

### 3. 知识图谱

- `kg_node` - 知识点节点
- `kg_edge` - 知识点关系边

### 4. 资源与任务

- `resource_meta` - 学习资源元数据
- `generation_task` - 资源生成任务状态

### 5. 测验

- `quiz_item` - 题目
- `quiz_attempt` - 答题记录

### 6. 学习路径

- `learning_path` - 学习路径
- `learning_path_item` - 路径中的知识点

### 7. 学习记录

- `learning_record` - 学习行为记录

## 初始化流程

```
FastAPI startup:
  1. init_db()        → 创建 MySQL 连接池
  2. init_vector_db() → 创建 ChromaDB 客户端
  3. 应用就绪

FastAPI shutdown:
  1. close_db()       → 释放连接池
```

## 会话使用

```python
from backend.db.database import get_session

@router.get("/users")
async def get_users(session: AsyncSession = Depends(get_session)):
    users = await select(session, User)
    return users
```
