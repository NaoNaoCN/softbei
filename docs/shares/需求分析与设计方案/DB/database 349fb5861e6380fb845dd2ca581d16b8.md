# Database - 数据库连接池与会话管理

## 概述

`database.py` 负责管理 MySQL/SQLite 数据库的连接池和异步会话。它使用 SQLAlchemy 2.x 的异步引擎，提供应用启动时的数据库初始化、会话获取和连接池管理功能。

## 核心组件

### 1. Base - ORM 基类

```python
class Base(DeclarativeBase):
    """所有 ORM 模型的基类"""
    pass
```

所有 ORM 模型（如 `User`、`KGNode` 等）都继承自 `Base`，继承后自动注册到 `Base.metadata`，用于 `create_all()` 创建表结构。

### 2. 模块级单例

```python
_engine: AsyncEngine | None = None
_session_factory: async_sessionmaker[AsyncSession] | None = None
```

采用模块级单例模式，确保整个应用共享同一个连接池。

## 核心函数

### `init_db()`

**作用**：创建引擎、建立连接池，开发模式下自动建表。

**调用时机**：FastAPI lifespan startup 阶段。

**配置参数**（来自 `backend.config`）：

| 参数 | 说明 |
| --- | --- |
| `config.url` | 数据库连接 URL |
| `config.echo` | 是否打印 SQL 语句 |
| `config.pool_size` | 连接池大小 |
| `config.max_overflow` | 超出 pool_size 的最大连接数 |
| `config.pool_timeout` | 获取连接超时时间（秒） |
| `config.pool_recycle` | 连接回收时间（秒） |

**SQLite 自动建表逻辑**：

```python
if "sqlite" in config.url:
    _import_models()  # 导入所有模型以注册到 Base.metadata
    async with _engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)
```

### `close_db()`

**作用**：释放连接池。

**调用时机**：FastAPI lifespan shutdown 阶段。

```python
async def close_db() -> None:
    global _engine
    if _engine:
        await _engine.dispose()
        _engine = None
```

### `get_session()`

**作用**：FastAPI Depends 依赖项，提供请求作用域的数据库会话。

**特点**：
- 自动 commit（无异常时）
- 自动 rollback（有异常时）
- 请求结束自动归还连接

```python
async def get_session() -> AsyncGenerator[AsyncSession, None]:
    async with _session_factory() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
```

**使用方式**：

```python
from fastapi import Depends

@router.get("/users/{user_id}")
async def get_user(
    user_id: uuid.UUID,
    session: AsyncSession = Depends(get_session)
):
    user = await select_by_id(session, User, user_id)
    return user
```

### `health_check()`

**作用**：检查数据库连通性。

```python
async def health_check() -> bool:
    try:
        async with get_engine().connect() as conn:
            await conn.execute(text("SELECT 1"))
        return True
    except Exception:
        return False
```

## 数据库配置

配置通过 `backend.config` 模块管理，通常从 `configs/` 目录下的 YAML 文件加载。

### 配置示例（YAML）

```yaml
database:
url:"mysql+aiomysql://user:password@localhost:3306/softbei"
echo:false
pool_size:10
max_overflow:20
pool_timeout:30
pool_recycle:3600

persist_dir:"./data/chroma"
collection:"knowledge_base"
```

### SQLite 开发配置

```yaml
database:
url:"sqlite+aiosqlite:///./data/softbei.db"
echo:true
```

## 异步会话的优势

| 对比项 | 同步 SQLAlchemy | 异步 SQLAlchemy |
| --- | --- | --- |
| 线程模型 | 阻塞 | 非阻塞 |
| 适用场景 | 脚本/CLI | Web 服务 |
| 并发能力 | 受 GIL 限制 | 高并发 |
| FastAPI 兼容 | 需用 run_in_executor | 原生支持 |

## 错误处理

`get_session` 依赖项自动处理事务：
- **正常流程**：`yield session` → 结束 → `session.commit()`
- **异常流程**：捕获异常 → `session.rollback()` → 重新抛出异常

## 与其他模块的关系

```
database.py
├── init_db()      → 被 main.py 或 lifespan 调用
├── get_session()  → 被 crud.py 和路由处理器使用
├── health_check()  → 被健康检查端点使用
└── close_db()     → 被 lifespan shutdown 调用
```
