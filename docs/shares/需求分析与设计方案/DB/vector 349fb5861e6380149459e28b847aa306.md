# vector

# Vector - 向量数据库（ChromaDB）管理

## 概述

`vector.py` 负责管理 ChromaDB 向量数据库的连接和集合操作。ChromaDB 是一个本地向量数据库，用于存储和检索文档的嵌入向量，支持语义搜索。当前使用本地持久化模式，后续可切换至 Qdrant 等其他向量数据库，只需替换本文件实现，接口保持不变。

## 核心配置

```python
CHROMA_PERSIST_DIR: str = config.vector_db.persist_dir    # 数据持久化目录
COLLECTION_NAME: str = config.vector_db.collection         # 默认集合名称
```

## 模块级单例

```python
_client: chromadb.ClientAPI | None = None
_collection: Collection | None = None
```

采用延迟初始化模式，首次使用时才创建客户端。

## 核心函数

### 1. init_vector_db() - 初始化

```python
def init_vector_db() -> None:
    """
    初始化 ChromaDB 客户端与默认集合。
    应在 FastAPI lifespan startup 阶段调用。
    """
```

**执行内容**：
1. 创建 `PersistentClient`（持久化客户端）
2. 获取或创建默认集合
3. 设置向量距离度量为 `cosine`（余弦相似度）

**使用方式**：

```python
from backend.db.vector import init_vector_db

# FastAPI lifespan
async def startup():
    init_vector_db()
```

### 4. upsert_documents() - 批量写入

```python
def upsert_documents(
    ids: list[str],
    documents: list[str],
    embeddings: list[list[float]],
    metadatas: Optional[list[dict]] = None,
    collection_name: Optional[str] = None,
) -> None
```

**功能**：将文档及其向量批量写入向量库。

**参数**：
| 参数 | 类型 | 说明 |
|——|——|——|
| ids | list[str] | 文档 ID 列表 |
| documents | list[str] | 文档内容列表 |
| embeddings | list[list[float]] | 向量列表（由嵌入模型生成） |
| metadatas | list[dict] | None | 元数据列表（如来源、知识点 ID 等） |
| collection_name | str | None | 集合名称（默认使用主集合） |

**使用示例**：

```python
upsert_documents(
    ids=["doc_001", "doc_002"],
    documents=["文档内容1", "文档内容2"],
    embeddings=[[0.1, 0.2, ...], [0.3, 0.4, ...]],
    metadatas=[
        {"kp_id": "kp_01", "course": "机器学习"},
        {"kp_id": "kp_02", "course": "机器学习"}
    ]
)
```

---

### 5. query_documents() - 向量检索

```python
def query_documents(
    query_embedding: list[float],
    n_results: int = 5,
    where: Optional[dict] = None,
    collection_name: Optional[str] = None,
) -> dict
```

**功能**：按向量相似度检索文档。

**参数**：
| 参数 | 类型 | 说明 |
|——|——|——|
| query_embedding | list[float] | 查询向量 |
| n_results | int | 返回结果数量，默认 5 |
| where | dict | None | 元数据过滤条件 |
| collection_name | str | None | 集合名称 |

**返回**：ChromaDB QueryResult 字典，包含：
- `ids`: 匹配的文档 ID 列表
- `documents`: 匹配的文档内容列表
- `distances`: 距离分数列表
- `metadatas`: 元数据列表

**使用示例**：

```python
results = query_documents(
    query_embedding=[0.1, 0.2, 0.3, ...],
    n_results=5,
    where={"kp_id": "kp_01"}
)

for doc, distance in zip(results["documents"], results["distances"]):
    print(f"文档:{doc}, 距离:{distance}")
```

## 向量数据库工作流程

```
┌──────────────────────────────────────────────────────────────┐
│                       RAG 流程                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  文档上传：                                                  │
│  文档 → 分块 → 嵌入模型 → 向量 → upsert_documents()          │
│                                                              │
│  语义检索：                                                  │
│  查询文本 → 嵌入模型 → 向量 → query_documents() → 文档       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 与 RAG 模块的关系

向量库操作的具体逻辑在 `backend/rag/` 目录中，本文件只提供底层接口：

```
backend/rag/
├── loader.py    → 调用 upsert_documents() 写入
├── indexer.py   → 调用 upsert_documents() 写入
├── retriever.py → 调用 query_documents() 检索
```

## 多集合场景

对于多课程场景，可以为每个课程创建独立的集合：

```python
# 课程 A 的知识库
collection_a = get_or_create_collection("course_a")
collection_a.upsert(...)

# 课程 B 的知识库
collection_b = get_or_create_collection("course_b")
collection_b.upsert(...)

# 检索时指定集合
results = query_documents(
    query_embedding=embedding,
    collection_name="course_a"
)
```

## ChromaDB 配置说明

| 配置项 | 说明 |
| --- | --- |
| `hnsw:space` | 向量距离度量方式，`cosine` 表示余弦相似度 |
| `anonymized_telemetry` | 是否发送匿名遥测数据，设为 False 禁用 |
