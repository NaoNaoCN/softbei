## 1. 什么是 LangGraph

LangGraph 是 LangChain 生态的多 Agent 编排框架，基于**有向图**结构来组织 Agent 的工作流程。

### 与传统 Agent 的区别

| 特性 | 传统 ReAct Agent | LangGraph 状态机 |
| --- | --- | --- |
| 结构 | 单 Agent 循环 | 有向图 |
| 流程控制 | 模型自己决定 | 显式定义 |
| 状态管理 | 累加在 messages | 集中式 State |
| 并行能力 | 顺序执行 | 支持并行分支 |
| 适用场景 | 简单问答 | 复杂工作流 |

### 核心思想

```
ReAct:  while not done:
            thought() → action() → observe()

LangGraph:  Graph execution with shared state
```

## 2. 核心概念

### 2.1 State（状态）

State 是整个图的**全局状态**，所有节点共享同一个状态对象。

```python
from pydantic import BaseModel
from typing import Optional

class AgentState(BaseModel):
    user_id: str
    session_id: str
    messages: list[str] = []
    profile: Optional[dict] = None
    result: Optional[str] = None
```

### 2.2 Node（节点）

Node 是图中的**执行单元**，本质是一个**函数**：

```python
def my_node(state: AgentState) -> AgentState:
    # 执行逻辑
    new_state = state.model_copy()
    new_state.messages.append("Hello from my_node")
    return new_state
```

### 2.3 Edge（边）

Edge 连接两个节点，定义执行顺序：

```python
# A 完成后一定执行 B
graph.add_edge("A", "B")

# 从 A 可以到达 B 或 C
graph.add_edge("A", "B")
graph.add_edge("A", "C")
```

### 2.4 Graph（图）

Graph 是节点和边组成的整体结构：

```python
from langgraph.graph import StateGraph

graph = StateGraph(AgentState)
# 添加节点、边
compiled = graph.compile()
```

## 3. 状态管理

### 3.1 状态更新机制

节点的返回值会被**合并**到全局状态中：

```python
class AgentState(BaseModel):
    counter: int = 0
    history: list[str] = []

def node_a(state: AgentState) -> AgentState:
    return {"counter": state.counter + 1}

def node_b(state: AgentState) -> AgentState:
    return {"history": state.history + ["processed"]}

# 执行后 state = {counter: 1, history: ["processed"]}
```

### 3.2 状态字段说明

| 字段类型 | 说明 | 示例 |
| --- | --- | --- |
| `str` | 字符串 | `user_id: str` |
| `int` | 整数 | `counter: int = 0` |
| `list[str]` | 列表，默认空 | `messages: list[str] = []` |
| `Optional[X]` | 可选字段 | `profile: Optional[dict]` |
| `dict[str, Any]` | 字典 | `metadata: dict = {}` |

### 3.3 状态初始化

```python
initial_state = AgentState(
    user_id="user_123",
    session_id="session_456",
    messages=[],
)

result = await compiled_graph.ainvoke(initial_state)
```

## 4. 节点定义

### 4.1 基本结构

节点是一个**纯函数**，接收当前状态，返回更新后的状态：

```python
async def profile_agent(state: AgentState) -> AgentState:
    """
    Profile Agent: 更新用户画像
    """
    # 1. 获取用户消息
    user_message = state.user_message

    # 2. 调用 LLM 分析
    analysis = await analyze_profile(user_message)

    # 3. 更新状态
    return {
        "profile": analysis,
        "metadata": {"agent": "profile_agent", "timestamp": now()}
    }
```

### 4.2 同步 vs 异步

```python
# 同步节点
def sync_node(state: AgentState) -> AgentState:
    return {"result": "sync"}

# 异步节点
async def async_node(state: AgentState) -> AgentState:
    result = await some_async_call()
    return {"result": result}
```

### 4.3 节点注册

```python
graph = StateGraph(AgentState)

# 注册节点，第二个参数是节点函数
graph.add_node("profile_agent", profile_agent)
graph.add_node("planner_agent", planner_agent)
```

## 5. 边的连接

### 5.1 顺序边

最简单的连接方式，A 完成后一定执行 B：

```python
# profile → planner → end
graph.add_edge("profile_agent", "planner_agent")
graph.add_edge("planner_agent", END)
```

### 5.2 分支边

一个节点可以连接多个后续节点：

```python
# planner 可以到达多个下游节点
graph.add_edge("planner_agent", "doc_agent")
graph.add_edge("planner_agent", "quiz_agent")
graph.add_edge("planner_agent", "mindmap_agent")
```

### 5.3 边的方向示意

```

    │profile_agent│
    └──────┬───────┘

    ┌──────────────┐

┌────────┐  ┌────────┐
│doc_    │  │quiz_   │
│agent   │  │agent   │
```

## 6. 条件路由

### 6.1 基本用法

根据当前状态动态决定下一步走哪个节点：

```python
def route_by_type(state: AgentState) -> str:
    """根据资源类型路由"""
    resource_type = state.resource_type

    if resource_type == "doc":
        return "doc_agent"
    elif resource_type == "quiz":
        return "quiz_agent"
    elif resource_type == "mindmap":
        return "mindmap_agent"
    else:
        return "recommend_agent"

# 注册条件边
graph.add_conditional_edges(
    "planner_agent",      # 源节点
    route_by_type,         # 路由函数
    {
        "doc_agent": "doc_agent",
        "quiz_agent": "quiz_agent",
        "mindmap_agent": "mindmap_agent",
        "recommend_agent": "recommend_agent",
    }
)
```

### 6.2 路由函数签名

```python
def route_func(state: AgentState) -> Literal["node_a", "node_b", ...]:
    """
    返回值必须是字符串，对应目标节点名称
    """
    ...
```

### 6.3 条件路由图示

```
              ┌─────────────────┐
              │ planner_agent   │
              └────────┬────────┘
                       │
              route_by_resource_type()
                       │
        ┌───────────────┼───────────────┐
        ↓               ↓               ↓
   ┌─────────┐    ┌─────────┐    ┌─────────────┐
   │doc_agent│    │quiz_agent│   │mindmap_agent│
   └─────────┘    └─────────┘    └─────────────┘
```

## 7. 图的编译与执行

### 7.1 编译

```python
# 创建图
graph = StateGraph(AgentState)

# 添加节点和边
graph.add_node("A", node_a)
graph.add_node("B", node_b)
graph.add_edge("A", "B")

# 编译成可执行图
compiled = graph.compile()
```

### 7.2 同步执行

```python
initial_state = AgentState(user_id="123", ...)

# 一次性执行到结束
result = compiled.invoke(initial_state)
```

### 7.3 异步执行

```python
result = await compiled.ainvoke(initial_state)
```

### 7.4 流式执行

逐步获取中间状态，适合前端实时展示：

```python
async for event in compiled.astream(initial_state):
    print(event)  # 每个节点的输出
```

### 7.5 图的检查点（Checkpoint）

LangGraph 支持状态持久化和恢复（需要 Checkpoint 存储）：

```python
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
compiled = graph.compile(checkpointer=checkpointer)

# 从检查点恢复
result = compiled.invoke(initial_state, config={"configurable": {"thread_id": "123"}})
```

### 8.4 节点注册代码

```python
def build_graph() -> StateGraph:
    graph = StateGraph(AgentState)

    # 注册所有节点
    graph.add_node("profile_agent", profile_agent.run)
    graph.add_node("planner_agent", planner_agent.run)
    graph.add_node("doc_agent", doc_agent.run)
    graph.add_node("mindmap_agent", mindmap_agent.run)
    graph.add_node("quiz_agent", quiz_agent.run)
    graph.add_node("code_agent", code_agent.run)
    graph.add_node("summary_agent", summary_agent.run)
    graph.add_node("safety_agent", safety_agent.run)
    graph.add_node("recommend_agent", recommend_agent.run)

    # 设置入口节点
    graph.set_entry_point("profile_agent")

    # profile → planner（固定顺序）
    graph.add_edge("profile_agent", "planner_agent")

    # planner → 条件路由
    graph.add_conditional_edges(
        "planner_agent",
        planner_agent.route_by_resource_type,
        {
            "doc_agent": "doc_agent",
            "mindmap_agent": "mindmap_agent",
            "quiz_agent": "quiz_agent",
            "code_agent": "code_agent",
            "summary_agent": "summary_agent",
            "recommend_agent": "recommend_agent",
        }
    )

    # 各生成 Agent → safety_agent
    for agent_name in ["doc_agent", "mindmap_agent", "quiz_agent", "code_agent", "summary_agent"]:
        graph.add_edge(agent_name, "safety_agent")

    # safety → recommend →END
    graph.add_edge("safety_agent", "recommend_agent")
    graph.add_edge("recommend_agent", END)

    return graph.compile()
```

### 8.5 执行入口

```python
# 模块级缓存
_compiled_graph = None

def get_graph():
    """获取已编译的图（单例模式）"""
    global _compiled_graph
    if _compiled_graph is None:
        _compiled_graph = build_graph()
    return _compiled_graph

async def invoke(user_id: str, session_id: str, message: str) -> AgentState:
    """同步执行一次完整推理"""
    initial_state = AgentState(
        user_id=user_id,
        session_id=session_id,
        user_message=message,
    )
    result = await get_graph().ainvoke(initial_state)
    return AgentState(**result)

async def stream_invoke(user_id: str, session_id: str, message: str):
    """流式执行，逐步 yield 状态"""
    initial_state = AgentState(
        user_id=user_id,
        session_id=session_id,
        user_message=message,
    )
    async for event in get_graph().astream(initial_state):
        yield event
```

## 10. 最佳实践

### 10.1 状态设计

```python
# ✅ 推荐：使用 Pydantic 模型定义状态
class AgentState(BaseModel):
    user_id: str
    messages: list[str] = []

# ❌ 避免：使用简单字典
state = {"user_id": "123", "messages": []}
```

### 10.2 节点设计

```python
# ✅ 推荐：单一职责，返回部分状态更新
async def profile_agent(state: AgentState) -> AgentState:
    profile = await analyze_profile(state.user_message)
    return {"profile": profile}

# ✅ 推荐：异步操作使用 async def
async def llm_call(state: AgentState) -> AgentState:
    result = await chat_completion(...)
    return {"result": result}

# ❌ 避免：在节点中做状态持久化（应该在外面做）
```

### 10.3 图的编译

```python
# ✅ 推荐：使用单例模式避免重复编译
_compiled_graph = None

def get_graph():
    global _compiled_graph
    if _compiled_graph is None:
        _compiled_graph = build_graph().compile()
    return _compiled_graph
```

### 10.4 错误处理

```python
async def safe_agent(state: AgentState) -> AgentState:
    try:
        result = await risky_operation()
        return {"result": result}
    except Exception as e:
        return {"error": str(e), "safety_passed": False}
```

### 10.5 调试技巧

```python
# 1. 使用流式执行查看中间状态
async for event in compiled.astream(initial_state):
    print(f"Node:{event.keys()}")
    print(f"State:{event}")

# 2. 添加打印节点
def debug_node(state: AgentState) -> AgentState:
    print(f"Debug:{state}")
    return {}

graph.add_node("debug", debug_node)
graph.add_edge("profile_agent", "debug")
```

## 附录：常见问题

### Q1: 如何让节点并行执行？

LangGraph 本身不支持同一节点的并行，但可以通过条件边实现”分发-收集”模式。

### Q2: 如何实现循环？

添加一条回到之前节点的边即可形成循环：

```python
graph.add_edge("current_node", "previous_node")  # 形成循环
```

### Q3: 如何中断执行？

```python
# 返回END 常量
graph.add_edge("node", END)  # 正常结束

# 或者在节点中设置标志位
return {"should_end": True}
```

### Q4: 如何查看图的结构？

```python
# 导出图形化表示
compiled = graph.compile()
print(compiled.get_graph().draw_ascii())
```
