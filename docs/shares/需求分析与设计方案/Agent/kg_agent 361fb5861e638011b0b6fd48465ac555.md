# kg_agent

# **KGAgent - 知识图谱构建智能体**

# **概述**

KGAgent 负责从已导入的 PDF 文档自动构建知识图谱（`KGNode` + `KGEdge`）。它调用 `kg_builder` 服务提取知识点和推断关系，构建可视化图谱结构。

## **核心职责**

1. **文档定位** - 从 `state.kg_doc_id` 或 `state.metadata["doc_id"]` 获取目标文档 ID
2. **图谱构建** - 调用 `kg_builder.build_kg()` 提取知识点和关系
3. **结果反馈** - 生成构建报告（知识点数量、关系数量）
4. **异常兜底** - 无数据库/无文档 ID/构建失败时写入友好提示

## **输入与输出**

### **输入（AgentState）**

| 字段 | 说明 |
| --- | --- |
| `kg_doc_id` | 目标文档 ID（直接传入） |
| `metadata["doc_id"]` | 目标文档 ID（备用） |
| `kp_id` | （可能误传文档名，用于容错提示） |

### **输出（AgentState 更新）**

| 字段 | 说明 |
| --- | --- |
| `final_content` | 构建报告或错误提示 |
| `draft_content` | 构建报告（与 final_content 一致） |
| `metadata["kg_result"]` | 构建结果详情（`nodes_count`、`edges_count`） |
| `error` | 错误信息（构建失败时） |

## **执行流程**

1. **获取数据库连接**：
    - 从 `config["configurable"]["db"]` 获取
    - **无连接** → 写入失败提示，返回
2. **获取文档 ID**：
    - 优先 `state.kg_doc_id`，其次 `state.metadata["doc_id"]`
    - **无文档 ID** → 写入引导提示（告诉用户去资源库选择 PDF），返回
3.  **调用 `build_kg(doc_id, db)`**：
    - 返回 `{"nodes_count": N, "edges_count": M}`
4. **生成构建报告**：
    
    ```
    知识图谱构建完成！
    - 文档 ID: {doc_id}- 提取知识点: {nodes_count} 个- 推断关系: {edges_count} 条
    您可以前往「学习路径」页面查看知识图谱可视化。
    ```
    
5. **写入 state**：
    - `final_content` = `draft_content` = 报告
    - `metadata["kg_result"]` = 构建结果
6. **异常处理**：
    - `ValueError` → 写入失败原因（如文档不存在）
    - 其他异常 → 记录 exception 日志，写入错误提示

## **依赖关系**

- **上游**：PlannerAgent（用户请求构建知识图谱时路由）
- **下游**：RecommendAgent（构建完成后推荐学习路径）
