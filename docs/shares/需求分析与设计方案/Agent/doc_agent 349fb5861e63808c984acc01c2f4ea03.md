# DocAgent - 文档生成智能体

## 概述

DocAgent 基于 RAG（检索增强生成）技术，生成结构化的学习文档（Markdown 格式）。它是一位专业的教学资料撰写专家，能够根据参考资料和知识点信息，生成适配学生画像的文档内容。

## 核心职责

1. **调用检索器** - 根据 `kp_id` 检索知识点相关的文档片段
2. **RAG 生成** - 构造包含上下文的 prompt，调用 LLM 生成 Markdown 文档
3. **来源标注** - 在文档中以 `[n]` 形式标注参考来源
4. **异常兜底与降级** - RAG 检索失败时降级为纯 LLM 生成，LLM 调用失败时写入失败提示，不中断状态机

## System Prompt

```
你是一位专业的教学资料撰写专家。
请根据提供的参考资料和知识点信息，生成一份结构清晰、内容准确的学习文档。
要求：
- 使用 Markdown 格式，包含标题、正文、例子和小结
- 内容必须基于参考资料，不得捏造
- 在引用参考资料时，以 [n] 形式标注来源编号
- 难度和深度适配学生当前画像

参考资料：
{context}

知识点：{kp_name}
```

## 输入与输出

### 输入（AgentState）

| 字段 | 说明 |
| --- | --- |
| `kp_id` | 目标知识点 ID |
| `profile` | 学生画像信息（用于调整难度） |
| `retrieved_docs` | 检索到的文档文本列表 |

### 输出（AgentState 更新）

| 字段 | 说明 |
| --- | --- |
| `retrieved_docs` | 检索到的文档文本列表 |
| `draft_content` | 生成的 Markdown 文档内容 |

## 执行流程

```
1. 通过 resolve_kp_name 从 kp_id 获取知识点名称 kp_name，并记录日志
2. 检索 context（优先检索包含代码的文档块，n_results=5）
3. RAG 检索到文档时记录日志（条数），未检索到时记录 warning，检索异常时记录 warning 并降级
4. 构造 context = format_context(chunks, max_tokens=3000)
5. 填充 SYSTEM_PROMPT 中的 {context}、{kp_name}
6. 调用 chat_completion 生成文档 （新增参数 max_tokens=4000）
7. 记录日志：生成成功 / 失败
8. 将结果写入 state.draft_content
9. 异常时写入 "文档生成失败：{e}"，不抛异常中断 graph
```

## 依赖关系

- **下游**：SafetyAgent（内容安全审核）
