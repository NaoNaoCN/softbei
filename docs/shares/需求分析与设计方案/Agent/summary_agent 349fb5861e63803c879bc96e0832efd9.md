# SummaryAgent - 知识点总结生成智能体

## 概述

SummaryAgent 负责生成知识点的精简总结，适合学生快速复习使用。它是一位学习总结专家，能够从参考文档中提炼核心要点，突出常见误区和记忆技巧。

## 核心职责

1. **检索文档** - 获取知识点的相关参考资料
2. **要点提炼** - 调用 LLM 生成简洁的复习总结
3. **格式控制** - 生成要点式 Markdown，控制在 300-500 字
4. **异常兜底** - LLM 调用失败时写入友好提示，不中断状态机

## System Prompt

```
你是一位学习总结专家。
请根据参考资料，为以下知识点生成一份简洁的复习总结，要求：
- 使用要点式 Markdown（无序列表 + 加粗重点词）
- 控制在 300-500 字以内
- 突出核心概念、常见误区和记忆技巧
- 若知识点有公式，用 LaTeX 格式列出

参考资料：{context}
知识点：{kp_name}
```

## 输入与输出

### 输入（AgentState）

| 字段 | 说明 |
| --- | --- |
| `kp_id` | 目标知识点 ID |
| `retrieved_docs` | 检索到的参考文档 |
| `user_id` | 用户 ID（RAG 检索过滤） |

### 输出（AgentState 更新）

| 字段 | 说明 |
| --- | --- |
| `draft_content` | 复习总结内容（Markdown 格式） |
| `retrieved_docs` | 更新为本次检索到的文档文本列表 |

## 输出格式示例

```markdown
## 线性回归核心要点

-**定义**：用线性函数拟合因变量和自变量之间的关系
-**目标**：最小化预测值与真实值的平方误差
-**常用公式**：$y = wx + b$
-**常见误区**：
  -混淆线性与非线性关系
  -忽略异常值对模型的影响
-**记忆技巧**：把"回归"理解为"回到平均水平"
```

## 约束条件

- **字数**：300-500 字
- **格式**：要点式 Markdown，使用无序列表和加粗
- **公式**：LaTeX 格式（如有）
- **内容**：核心概念 + 常见误区 + 记忆技巧

## **执行流程**

1. 通过 `resolve_kp_name` 从 `kp_id` 获取知识点名称 `kp_name`
2. 记录日志：打印 `kp_name`
3. 检索 context（优先检索包含代码的文档块，`n_results=5`）
4. RAG 检索到文档时记录日志（条数），未检索到时记录 warning，检索异常时记录 warning 并降级
5. 构造 `context = format_context(chunks, max_tokens=3000)`
6. 填充 SYSTEM_PROMPT 中的 `{context}`、`{kp_name}`
7. 调用 `chat_completion` 生成总结（`temperature=0.7`, `max_tokens=1200`）
8. 记录日志：打印 `draft_len`
9. 异常兜底：
    - 成功 → 写入 `draft_content`
    - 失败 → 写入 `"总结生成失败：{e}"`

## 依赖关系

- **上游**：PlannerAgent（确定 kp_id 和 resource_type）
- **下游**：SafetyAgent（内容安全审核）
