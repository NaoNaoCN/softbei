# graph

# LangGraph 状态机 - Agent 协作框架

## 概述

`graph.py` 定义了整个 Agent 系统的核心状态机，采用 LangGraph 实现。它编排所有 Agent 节点的执行顺序、条件路由和状态传递，是整个多智能体系统的调度中枢。

## 架构设计

### 节点拓扑

```
START → profile_agent
├─ (画像不足) → END
└─ (画像足够) → planner_agent
│ (先判断 intent_type)
├─ intent="clarify" → clarify_agent → END
│
│ (intent="generate", 按 resource_type 路由)
├─ doc_agent ─────┐
├─ mindmap_agent ─┤
├─ quiz_agent ────┼─→ safety_agent → recommend_agent → END
├─ code_agent ────┤
├─ summary_agent ─┘
├─ kg_agent ──────────────────────→ recommend_agent → END
└─ recommend_agent → END           ← 兜底路由
```

### 节点说明

| 节点 | 职责 | 状态更新 |
| --- | --- | --- |
| `profile_agent` | 提取/更新学生画像 | `profile` |
| `planner_agent` | 解析意图，确定资源类型和目标知识点 | `resource_type`, `kp_id` |
| `doc_agent` | 生成学习文档 | `draft_content` |
| `mindmap_agent` | 生成思维导图 | `draft_content` |
| `quiz_agent` | 生成测验题目 | `draft_content` |
| `code_agent` | 生成代码示例 | `draft_content` |
| `summary_agent` | 生成知识点总结 | `draft_content` |
| `safety_agent` | 内容安全审核 | `final_content`, `safety_passed` |
| `recommend_agent` | 学习推荐 | `metadata["recommendations"]` |
| `kg_agent` | 知识图谱构建 | `kg_nodes`, `kg_edges` |
| `clarify_agent` | 生成追问/引导内容（画像不完整或无资源请求时） | `clarify_message, final_content` |

## 边（Edge）规则

### 固定边

- `profile_agent` → `planner_agent`（画像不足直接 END）
- `safety_agent` → `recommend_agent`（始终执行）
- `recommend_agent` → `END`（终止）
- `kg_agent` → `recommend_agent` （知识图谱构建完成直连推荐）
- `clarify_agent` → `END` （追问/引导后直接结束，无需 safety）

### 条件边

**Profile Agent 条件路由**（按画像完整性）：

```
graph.add_conditional_edges(
    "profile_agent",
    profile_agent.route_after_profile,
    {
        "planner_agent": "planner_agent",  # 画像足够
        END: END,                           # 画像不足，追问
    },
)
```

**Planner Agent 条件路由**（按 `resource_type`）：

```
graph.add_conditional_edges(
    "planner_agent",
    planner_agent.route_by_resource_type,
    {
        "doc_agent": "doc_agent",
        "mindmap_agent": "mindmap_agent",
        "quiz_agent": "quiz_agent",
        "code_agent": "code_agent",
        "summary_agent": "summary_agent",
        "kg_agent": "kg_agent",
        "clarify_agent": "clarify_agent",  
        "recommend_agent": "recommend_agent",  
    },
)
```

**生成 Agent → Safety**（所有生成 Agent 都连接到 safety_agent）：

```
doc_agent       → safety_agent
mindmap_agent   → safety_agent
quiz_agent      → safety_agent
code_agent      → safety_agent
summary_agent   → safety_agent
```

## 核心函数

`build_graph() -> StateGraph`
构建并编译 LangGraph 状态机，注册所有节点和边。

`get_graph() -> CompiledGraph`
返回已编译的图实例（模块级单例）。

`invoke(user_id, session_id, message, db) -> AgentState`
同步执行一次完整的图推理，返回最终状态。

`stream_invoke(user_id, session_id, message, db)`
流式执行图推理，逐步 yield AgentState 快照，供 FastAPI StreamingResponse 或前端实时显示使用。

`_run_with_db(node_func, state, db) -> AgentState`
通用包装器：如果 node_func 签名需要 db，则传递。

## 调用示例

```python
# 同步调用
result = await invoke(
    user_id="xxx",
    session_id="yyy",
    message="我想学习卷积",
    db=db_session
)

# 流式调用
async for event in stream_invoke(
    user_id="xxx",
    session_id="yyy",
    message="我想学习卷积",
    db=db_session
):
    print(event)
```
