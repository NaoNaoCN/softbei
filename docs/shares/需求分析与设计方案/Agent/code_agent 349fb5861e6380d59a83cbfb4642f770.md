# CodeAgent - 代码生成智能体

## 概述

CodeAgent 负责生成与知识点相关的代码示例或编程练习题。它是一位编程教学专家，能够根据学生的画像和知识点信息，生成适配的代码内容。

## 核心职责

1. **检索相关文档** - 优先检索包含代码示例的文档片段
2. **生成代码内容** - 调用 LLM 生成包含详细注释的 Python 代码
3. **结构化输出** - 将生成的代码写入 `state.draft_content`
4. **异常兜底** - LLM 调用失败时写入失败提示，不中断状态机

## System Prompt

```
你是一位编程教学专家。
请为以下知识点生成一个编程练习（含完整参考答案），要求：
- 使用 Python（除非学生有特殊要求）
- 题目描述简洁明了，控制在 10 行以内，不要过度展开
- 参考答案必须是完整可运行的代码，包含详细注释
- 用 "# ===== 参考答案 =====" 分隔题目和答案
- 答案代码是最重要的部分，必须完整输出，不得省略

输出格式（Markdown）：
## 题目描述
（简要描述题目要求）

# ===== 参考答案 =====
```python
（完整的参考答案代码）
```

参考资料：
{context}

知识点：{kp_name}
学生画像：{profile_summary}
```

## 输入与输出

### 输入（AgentState）

| 字段 | 说明 |
| --- | --- |
| `kp_id` | 目标知识点 ID |
| `profile` | 学生画像信息 |
| `retrieved_docs` | 检索到的参考文档 |

### 输出（AgentState 更新）

| 字段 | 说明 |
| --- | --- |
| `draft_content` | 生成的代码内容（Markdown 格式） |
| `retrieved_docs` | 更新为本次检索到的文档文本列表 |

## 执行流程

```
1. 通过 resolve_kp_name 从 kp_id 获取知识点名称 kp_name
1. 检索 context（优先检索包含代码的文档块，n_results=5）
2. 构造 profile_summary
3. 填充 SYSTEM_PROMPT 中的 {context}、{kp_name}、{profile_summary}
4. 调用 chat_completion 生成代码
5. 记录日志：draft_len、是否含 fence、预览 200 字符
6. 将结果写入 state.draft_content
7. 异常时写入 `"代码生成失败：{e}"`，不抛异常中断 graph
```

## 依赖关系

- **上游**：PlannerAgent（确定 kp_id 和 resource_type）
- **下游**：SafetyAgent（内容安全审核）
