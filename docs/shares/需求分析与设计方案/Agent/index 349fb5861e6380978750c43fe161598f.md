| Agent | 职责 | 资源类型 |

## 系统架构

整个 Agent 系统采用 **LangGraph 状态机** 进行编排，详见 [graph.md](graph.md)。

### 处理流程

1. **入口**：`profile_agent` - 提取/更新学生画像
2. **路由**：`profile_agent` → （画像不足直接 END，足够则进 `planner_agent`）
3. **调度**：`planner_agent` - 解析意图，确定资源类型和知识点
4. **生成**：根据 `resource_type` 路由到对应的生成 Agent
5. **审核**：`safety_agent` - 审核生成内容
6. **推荐**：`recommend_agent` - 推荐下一步学习（末端节点）

### 状态传递

各 Agent 通过 `AgentState` 共享状态，包含以下关键字段：

- `user_id`、`session_id`、`user_message` - 用户身份与输入
- `profile` - 学生画像
- `chat_history` - 多轮对话历史（用于上下文理解）
- `kp_id` - 目标知识点 ID
- `resource_type` - 资源类型
- `intent_type` - 意图类型（`generate` / `clarify`）
- `retrieved_docs` - 检索到的文档
- `draft_content` - 草稿内容
- `final_content` - 最终内容
- `clarify_message` - 追问/引导消息
- `profile_complete` - 画像是否完整
- `safety_passed` - 安全审核是否通过
- `error` - 错误信息
- `metadata` - 附加元数据（如推荐列表）
