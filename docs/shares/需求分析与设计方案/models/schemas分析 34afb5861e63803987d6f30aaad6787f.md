# schemas分析

## 一、模块定位

**文件位置**：`backend/models/schemas.py`

**核心作用**：定义项目中所有 **Pydantic v2** 数据模型，作为 FastAPI 路由、Agent 系统以及前后端 API 调用的**统一数据类型规范**。

```
┌─────────────────────────────────────────────────────────────┐
│                    backend/models/schemas.py                  │
│              （Pydantic v2 统一数据模型层）                    │
├─────────────────────────────────────────────────────────────┤
│  FastAPI 路由    ←→    Agent 系统    ←→    前端 API 调用    │
│  (请求/响应)            (状态传递)            (类型安全)       │
└─────────────────────────────────────────────────────────────┘
```

## 三、枚举定义

### 3.1 ResourceType — 资源类型

```python
class ResourceType(str, Enum):
    doc = "doc"         # 学习文档
    mindmap = "mindmap" # 思维导图
    quiz = "quiz"       # 测验题目
    code = "code"       # 代码示例
    summary = "summary" # 知识总结
```

### 3.2 TaskStatus — 生成任务状态

```python
class TaskStatus(str, Enum):
    pending = "pending" # 等待中
    running = "running" # 执行中
    done = "done"       # 已完成
    failed = "failed"   # 失败
```

### 3.3 KGNodeType — 知识图谱节点类型

```python
class KGNodeType(str, Enum):
    Course = "Course"          # 课程
    Chapter = "Chapter"        # 章节
    KnowledgePoint = "KnowledgePoint"  # 知识点
    SubPoint = "SubPoint"      # 子知识点
    Concept = "Concept"        # 概念
```

### 3.4 KGRelation — 知识图谱关系类型

```python
class KGRelation(str, Enum):
    IS_PART_OF = "IS_PART_OF"  # 属于

    RELATED_TO = "RELATED_TO"  # 相关
    CONTAINS = "CONTAINS"      # 包含
```

### 3.5 QuestionType — 题目类型

```python
class QuestionType(str, Enum):
```

### 4.9 AgentState — LangGraph 全局状态

**核心模型**，定义 Agent 工作流中各节点间的数据传递格式：

```python
class AgentState(BaseModel):
    """LangGraph 全局状态，在各 Agent 节点间传递"""
    user_id: str                              # 用户ID
    session_id: str                            # 会话ID
    user_message: str                          # 用户原始消息
    chat_history: list[dict[str, str]] = []    # 多轮对话历史
    intent_type: Optional[str] = None          # "generate" | "clarify"
    profile: Optional[StudentProfileIn] = None # 学生画像
    kp_id: Optional[str] = None                # 目标知识点ID
    resource_type: Optional[ResourceType] = None# 资源类型
    retrieved_docs: list[str] = []              # RAG检索到的文档
    draft_content: Optional[str] = None         # 草稿内容（生成中）
    final_content: Optional[str] = None        # 最终内容（审核后）
    safety_passed: bool = True                  # 安全审核是否通过
    error: Optional[str] = None                # 错误信息
    metadata: dict[str, Any] = {}               # 扩展元数据
    kg_doc_id: Optional[str] = None             # 知识图谱构建的目标文档ID
    # 画像初始化/追问流程控制
    is_onboarding: bool = False                 # 前端标记：当前是否处于画像初始化阶段
    profile_complete: bool = False              # profile_agent判断后写入，供条件路由使用
    clarify_message: Optional[str] = None      # 追问内容，情况A/B时写入，透传给前端
    num_questions: int = 4                     # 测验题目数量
    question_type_counts: dict[str, int] = {}  # 各题型数量，如 {"single":5,"multi":3,"fill":2}
```

```

│                                            summary]_agent        │
│                                                  │               │
│                                                  ▼               │
```

## 五、关键设计模式

### 5.1 Input/Output 分离

对于需要双向传输的数据，采用 **In/Out 配对**模式：

| 输入模型 | 输出模型 | 说明 |
| --- | --- | --- |
| `UserCreate` | `UserOut` | 注册请求 vs 用户响应 |
| `StudentProfileIn` | `StudentProfileOut` | 画像更新 vs 画像响应 |
| `ChatMessageIn` | `ChatMessageOut` | 发送消息 vs 消息响应 |
| `QuizSubmitIn` | `QuizAttemptOut` | 答题提交 vs 答题结果 |
| `LearningRecordCreate` | `LearningRecordOut` | 记录创建 vs 记录响应 |

### 5.2 继承与组合

- `StudentProfileOut(StudentProfileIn)` — 输出继承输入，减少重复定义
- `LearningRecordOut(LearningRecordCreate)` — 同上
- `QuizAttemptOut` 包含题目详情字段
- `model_config = {"from_attributes": True}` — 启用 ORM 模式，支持从 SQLAlchemy 模型直接转换

### 5.3 枚举约束

使用 `str, Enum` 让枚举值序列化为字符串，便于 JSON 传输和数据库存储：

```python
class ResourceType(str, Enum):
    doc = "doc"
```

## 六、与其他模块的关系

```
schemas.py
    │
    ├──→ FastAPI 路由 (main.py)
    │        使用 Pydantic 模型作为请求/响应体
    │
    ├──→ Agent 系统 (agents/)
    │        使用 AgentState 定义状态流转
    │
    ├──→ 数据库模型 (db/models.py)
    │        model_config = {"from_attributes": True}
    │        实现 ORM 模型 ↔ Pydantic 模型互转
    │
    └──→ 前端 (frontend/)
             接收 JSON 响应，前端类型对应 Pydantic 模型
```

```python
from backend.models.schemas import AgentState, ResourceType

def mindmap_agent(state: AgentState) -> AgentState:
    state.resource_type = ResourceType.mindmap
    state.draft_content = generate_mindmap(...)
```

### 7.3 ORM 模型转换

```python
from backend.models.schemas import UserOut

# SQLAlchemy 模型 → Pydantic 模型
user_orm = await db.get(User, user_id)
user_out = UserOut.model_validate(user_orm)  # from_attributes=True
```
