# **generation.py** 调用关系详解

> 文件路径：`backend/services/generation.py`
本文档说明其中八个公开函数的**输入来源、输出去向、以及每个调用方的具体使用方式**。

---

### **一、`run_generation()` — 后台资源生成任务**

### **函数签名**

`async def run_generation(    task_id: uuid.UUID,    user_id: str,    session_id: str,    request: dict,) -> None`

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **触发时机** | FastAPI BackgroundTasks，任务创建成功后异步执行 |
| **文件位置** | `backend/services/generation.py:31` |
| **输入 `task_id`** | GenerationTask UUID |
| **输入 `request`** | `GenerateRequest` 序列化的 dict |
| **内部操作** | 1. 更新任务状态为 running + progress=10 → 2. 调用 `get_graph().ainvoke()` 执行 Agent Pipeline → 3. 持久化内容到 ResourceMeta → 4. quiz 类型额外写 quiz_item 表 → 5. 更新任务状态为 done + progress=100 → 6. 自动创建学习路径（兜底） |
| **输出** | 无（内部更新 GenerationTask + ResourceMeta） |
| **输出用途** | 后台执行生成任务，不阻塞前端 |

### **数据流**

`BackgroundTasks 触发  → run_generation(task_id, user_id, session_id, request)    → UPDATE generation_task SET status="running", progress=10    → 解析 kp_id → 知识点名称    → AgentState(user_id, session_id, user_message, kp_id, resource_type, ...)    → get_graph().ainvoke(initial_state, config={"db": db})      → profile_agent → planner_agent → [doc/mindmap/quiz/code/summary]_agent        → safety_agent → recommend_agent      → 返回 AgentState(final_content, metadata["recommendations"], ...)    → UPDATE generation_task SET progress=80    → 检测生成内容是否为错误信息    → 若 quiz 类型：      → _persist_quiz() → 解析 JSON → insert_many(quiz_item) + update(resource_meta.content_json)    → 若其他类型：      → _persist_content() → 写入 resource_meta.content / content_json    → UPDATE generation_task SET status="done", progress=100    → 兜底：若无学习路径则自动从推荐创建      → 获取 metadata["recommendations"]      → create_pathway() + add_pathway_item() × N`

### **二、`run_batch_generation()` — 批量并行生成**

### **函数签名**

`async def run_batch_generation(    batch_id: uuid.UUID,    user_id: str,    session_id: str,    task_configs: list[dict[str, Any]],) -> None`

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **触发时机** | 批量生成任务创建成功后异步执行 |
| **文件位置** | `backend/services/generation.py:260` |
| **输入 `task_configs`** | `[{"task_id": uuid, "request": dict}, ...]` |
| **内部操作** | 1. 更新 batch 状态为 running + progress=5 → 2. 并行执行 `asyncio.gather(*[_run_single(cfg)...])` → 3. 聚合结果，更新 batch 最终状态 |
| **输出** | 无 |
| **输出用途** | 后台并行执行多个资源生成任务 |

### **整体数据流总览**

`用户发起生成请求  → POST /generate {kp_id, resource_type, num_questions, question_type_counts}    → create_generation_task()      → INSERT resource_meta（type, kp_id, user_id, title）      → INSERT generation_task（status="pending", progress=0）      → 返回 GenerateTaskOut(task_id)    → BackgroundTasks: run_generation(task_id, ...)    → 返回 task_id，前端开始轮询
前端轮询  → GET /generate/{task_id}/status 每秒轮询    → 返回 {status, progress, result_id}    → 若 status=running → 显示 progress 进度条    → 若 status=done → 退出轮询 → GET /resources/{result_id}
后台执行（BackgroundTasks）  → run_generation(task_id, user_id, session_id, request)    → UPDATE generation_task SET status="running", progress=10    → get_graph().ainvoke(initial_state, config={"db": db})      → profile_agent（画像抽取）      → planner_agent（意图分类 + 资源类型决策）      → [doc/mindmap/quiz/code/summary]_agent（资源生成）      → safety_agent（内容安全审核）      → recommend_agent（推荐下一步）    → UPDATE generation_task SET progress=80    → _persist_content() 或 _persist_quiz()      → 更新 resource_meta.content / content_json      → quiz 类型额外 insert_many(quiz_item)    → UPDATE generation_task SET status="done", progress=100    → 兜底：自动创建学习路径      → 从 recommendations 获取知识点      → create_pathway() + add_pathway_item() × N`
