# pathway**.py** 调用关系详解

> 文件路径：`backend/services/pathway.py`
本文档说明其中八个公开函数的**输入来源、输出去向、以及每个调用方的具体使用方式**。
> 

---

### **一、`get_pathway()` — 查询单条学习路径**

### **函数签名**

`async def get_pathway(    path_id: uuid.UUID,    db: AsyncSession,) -> Optional[LearningPathOut]`

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **HTTP 路由** | `GET /pathways/{path_id}` |
| **输入 `path_id`** | 路径 UUID |
| **内部操作** | `SELECT * FROM learning_path WHERE id = ?` + loadRelations |
| **输出** | `LearningPathOut` 或 None |
| **输出用途** | 前端展示学习路径详情 |

---

### **二、`list_pathways()` — 列举用户学习路径**

### **函数签名**

`async def list_pathways(    user_id: uuid.UUID,    db: AsyncSession,) -> list[LearningPathOut]`

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **HTTP 路由** | `GET /pathways` |
| **输入 `user_id`** | 用户 UUID |
| **内部操作** | `SELECT * FROM learning_path WHERE user_id = ?` |
| **输出** | `list[LearningPathOut]` |
| **输出用途** | 前端渲染学习路径列表 |

### **三、`create_pathway()` — 创建学习路径**

### **函数签名**

`async def create_pathway(    user_id: uuid.UUID,    data: LearningPathCreate,    db: AsyncSession,) -> LearningPathOut`

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **HTTP 路由** | `POST /pathways` |
| **输入 `data`** | `LearningPathCreate(name, description)` |
| **内部操作** | `INSERT learning_path` |
| **输出** | `LearningPathOut` |
| **输出用途** | 前端创建新的学习路径 |

---

### **四、`add_pathway_item()` — 添加路径项**

### **函数签名**

`async def add_pathway_item(    path_id: uuid.UUID,    user_id: uuid.UUID,    data: LearningPathItemCreate,    db: AsyncSession,) -> Optional[LearningPathItemOut]`

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **HTTP 路由** | `POST /pathways/{path_id}/items` |
| **输入 `data`** | `LearningPathItemCreate(kp_id, order_index)` |
| **内部操作** | 1. 确认路径归属 → 2. 解析 kp_id（同户节点优先） → 3. `INSERT learning_path_item` |
| **输出** | `LearningPathItemOut` |
| **输出用途** | 向学习路径添加知识点项 |

### **数据流**

`用户添加知识点到路径  → add_pathway_item(path_id, user_id, data)    → SELECT learning_path WHERE id = path_id AND user_id = user_id    → 确认归属    → SELECT KGNode WHERE id = kp_id    → 若节点属于其他用户 → 按名称查找当前用户的同名节点    → INSERT learning_path_item(path_id, kp_id, order_index)    → 返回 LearningPathItemOut  → 前端刷新路径详情`

---

### **五、`update_pathway_item()` — 更新路径项（完成状态）**

### **函数签名**

`async def update_pathway_item(    item_id: uuid.UUID,    user_id: uuid.UUID,    data: LearningPathItemUpdate,    db: AsyncSession,) -> Optional[LearningPathItemOut]`

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **HTTP 路由** | `PATCH /pathways/items/{item_id}` |
| **输入 `data`** | `LearningPathItemUpdate(order_index, is_completed)` |
| **内部操作** | 1. 验证归属（item → path → user_id）→ 2. `UPDATE learning_path_item` → 3. 若 `is_completed=True` → `INSERT learning_record(action="complete")` |
| **输出** | `LearningPathItemOut` |
| **输出用途** | 用户点击「完成」时标记知识点已完成，同步写入学习记录 |

### **数据流**

`用户点击「完成」某个知识点  → update_pathway_item(item_id, user_id, {"is_completed": True})    → SELECT learning_path_item → path → 确认 user_id 归属    → UPDATE learning_path_item SET is_completed = True    → INSERT learning_record(user_id, kp_id, action="complete")      → 同步写入，以便「已学习视图」能识别    → SELECT 重新查询返回更新后数据  → 前端刷新路径状态`

---

### **六、`delete_pathway()` — 删除学习路径**

### **函数签名**

`async def delete_pathway(    path_id: uuid.UUID,    user_id: uuid.UUID,    db: AsyncSession,) -> bool`

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **HTTP 路由** | `DELETE /pathways/{path_id}` |
| **输入 `path_id`** | 路径 UUID |
| **内部操作** | 1. 确认归属 → 2. `DELETE learning_path_item WHERE path_id = ?` → 3. `DELETE learning_path` |
| **输出** | `bool` |
| **输出用途** | 删除整条学习路径（级联删除 items） |

### **整体数据流总览**

`用户进入学习路径页面  → GET /pathways    → list_pathways(user_id)      → SELECT learning_path WHERE user_id = ?      → 返回 list[LearningPathOut]  → 前端渲染路径列表（2 列网格布局）
用户创建新路径  → POST /pathways {name, description}    → create_pathway(user_id, data)      → INSERT learning_path      → 返回 LearningPathOut  → 前端刷新显示新路径
用户添加知识点到路径  → POST /pathways/{path_id}/items {kp_id, order_index}    → add_pathway_item(path_id, user_id, data)      → SELECT learning_path（确认归属）      → SELECT KGNode WHERE id = kp_id（同户节点优先）      → INSERT learning_path_item      → 返回 LearningPathItemOut  → 前端刷新路径详情
用户点击「完成」某个知识点  → PATCH /pathways/items/{item_id} {is_completed: true}    → update_pathway_item(item_id, user_id, {"is_completed": True})      → SELECT learning_path_item → path（确认归属）      → UPDATE learning_path_item SET is_completed = True      → INSERT learning_record(action="complete")        → 同步写入，以便「已学习视图」识别  → 前端刷新路径状态（显示 ✓ 已完成）
自动创建兜底路径（generation.run_generation）  → recommend_agent 返回 recommendations  → 若用户尚无学习路径    → create_pathway(user_id, {name: "知识点 学习路径"})    → add_pathway_item(path_id, user_id, {kp_id: rec["kp_id"], order_index: i}) × N`
