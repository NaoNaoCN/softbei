## **二、`truncate_history()` — 截断对话历史**

### **函数签名**

```python
def truncate_history(
    history: list[dict[str, str]],
    max_turns: int = DEFAULT_MAX_TURNS,
    max_tokens: int = DEFAULT_MAX_TOKENS,
) -> list[dict[str, str]]
```

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **调用方** | `load_chat_history()` 内部使用 |
| **输入 history** | 原始对话历史列表 `[{"role": "user"/"assistant", "content": "..."}]` |
| **截断策略** | 1. 先按 max_turns（默认 10 轮）截取最近 N 轮 → 2. 从最近往前累加 token，超出预算时截断 → 3. 保证从 user 消息开始（不会出现孤立的 assistant 消息） |
| **输出** | 截断后的历史列表 |

### **数据流**

```
原始 history（20 轮）
  → 截取最近 10 轮（max_turns=10）
  → 从后往前累加 token
    → 若加上当前消息超出 max_tokens（4000），则截断
  → 若首条是 assistant 消息则跳过
  → 返回截断后的历史
```

## **三、`load_chat_history()` — 加载并截断历史**

### **函数签名**

```python
async def load_chat_history(    
		session_id: str,    
		db: AsyncSession,    
		max_turns: int = DEFAULT_MAX_TURNS,    
		max_tokens: int = DEFAULT_MAX_TOKENS,
) -> list[dict[str, str]]
```

### **调用方**

| 项目 | 内容 |
| --- | --- |
| **调用方** | `backend/agents/graph.py` 初始化 AgentState 时 |
| **文件位置** | `backend/services/chat_history.py:68` |
| **输入 session_id** | 会话 UUID 字符串 |
| **内部操作** | 1. 查询 ChatSession 获取 messages_table → 2. 调用 `read_messages(table)` 读取历史 → 3. 转换为 `{"role": ..., "content": ...}` 列表 → 4. 调用 `truncate_history()` |
| **输出** | 截断后的历史消息列表 |
| **输出用途** | 注入 `AgentState.chat_history`，供各 Agent 理解上下文 |

### **数据流**

```
POST /chat/{session_id}
  → graph.invoke() / stream_invoke()
    → load_chat_history(session_id, db)
      → SELECT ChatSession WHERE id = session_id
      → 获取 messages_table（动态表名）
      → read_messages(messages_table) → list[dict]
      → 转换为 [{"role": "user"/"assistant", "content": "..."}]
      → truncate_history(history, max_turns, max_tokens)
      → AgentState(chat_history=[...])
    → 注入 profile_agent / planner_agent / clarify_agent
```

## **四、整体数据流总览**

```
用户发送消息 → POST /chat/{session_id}
  → graph.invoke() / stream_invoke()
    → load_chat_history(session_id, db)
      → SELECT ChatSession WHERE id = session_id
      → 获取 messages_table（动态表名）
      → read_messages(messages_table) → list[dict]
      → 转换为 [{"role": "user"/"assistant", "content": "..."}]
      → truncate_history(history, max_turns=10, max_tokens=4000)
        → 截取最近 10 轮
        → 从后往前累加 token，超出 4000 时截断
        → 保证首条是 user 消息
      → AgentState(chat_history=[...])
    → profile_agent.run()
      → 注入 chat_history，理解上下文
      → 抽取画像字段 → merge_chat_updates()
    → planner_agent.run()
      → 注入 chat_history，判断意图（generate/clarify）
    → 若 intent=clarify → clarify_agent.run()
      → 注入 chat_history，直接回答
    → 若 intent=generate → [doc/mindmap/quiz/code/summary]_agent.run()
      → RAG 检索 → LLM 生成 → safety_agent → recommend_agent
    → 返回 final_content + metadata["recommendations"]
```
